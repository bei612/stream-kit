- 应用与组件启停共用资源命令互斥边界，按资源显示处理中与失败反馈，重复点击不重复提交同一命令，不同组件可独立操作。
- 工作台集中展示状态并直达组件管理；组件启停集中在管理页，停止态运行时长和错误提示统一呈现。
- 保留上一版的应用实例会话同步、历史记录有界清理、唯一控制权和配置式局域网证书维护能力。

## 安装和访问

Windows 管理员终端静默安装：

```powershell
.\stream-kit-preview-6546792a5ccd-windows-amd64-setup.exe /VERYSILENT /SUPPRESSMSGBOXES /SP- /NORESTART
```

Ubuntu 24.04 将 `RENDER_USER` 替换为实际拥有图形、音频会话的用户：

```sh
sudo bash stream-kit-preview-6546792a5ccd-ubuntu24.04-amd64-setup.run --user RENDER_USER
```

Windows 安装器创建自动启动的 `StreamKitOrchestrator` 系统服务，由该服务管理编码器和网关工作进程。渲染需要登录后的桌面会话；安装器不设置自动登录，也不自动重启电脑。程序运行无需宿主机另装 Node.js/npm，不依赖 VB-CABLE。Example、探针、测试 CA、测试凭据、模拟器和 SDK 不随运行安装包交付。

首次在服务器本机打开 `http://127.0.0.1:9000`，唯一管理员凭据位于受保护的运行配置。局域网客户端应使用服务器局域网地址；远程麦克风接入前配置监听、媒体地址与可信 HTTPS，再从应用页复制永久观看链接。配置 `server.lan_tls` 后，后续地址变更沿用原部署 CA 更新服务证书，保存配置并重启服务生效；数字 IP 书签需要相应更新地址部分。

已有安装、服务和运行数据受保护，本版安装器不提供原位升级。部署方法见 [Windows 说明](https://github.com/bei612/stream-kit/blob/main/deploy/windows/README.md)、[Linux 说明](https://github.com/bei612/stream-kit/blob/main/deploy/linux/README.md)和[局域网地址配置](https://github.com/bei612/stream-kit/blob/main/docs/lan-address-configuration.md)。
