# 云端渲染 0.1.1 RC5

本预发布提供 Windows 11 x64、Ubuntu 24.04 amd64 安装器及原生签名 Android APK。三个产物使用同一源码 `8bb57538c064bdf763bb153439b2c973e69afd3b`，Android `versionCode` 为 `1000034`。

- 服务器音频队列在播放完最后一对左右声道采样后立即释放对应槽位。Windows 托管安装验收录得 144,000 个采样帧，目标队列零丢块；同源 Windows 与 Android 通过程序声音、麦克风录音和撤权联验。[安装与录音](https://github.com/bei612/stream-kit/blob/main/docs/evidence/windows11-hosted-install-8bb57538-20261128.json) · [媒体联验及诊断边界](https://github.com/bei612/stream-kit/blob/main/docs/evidence/windows11-android-packaged-audio-8bb57538-20261128.json)
- Android 从 `v0.1.0` 覆盖安装后可打开原书签。原生 Android 与 Web 共享串流，支持控制权交接、撤权、录音权限拒绝、前后台恢复和断网重连。[跨端联验](https://github.com/bei612/stream-kit/blob/main/docs/evidence/android-input-8bb57538-20261128.json)
- Ubuntu 隔离局域网中，渲染服务器实际换 IPv4 后，两路 HTTPS 在 3.354 秒内更新证书，原观看页恢复画面与声音。部署 CA、应用配置和组件进程保持。[换址联验](https://github.com/bei612/stream-kit/blob/main/docs/evidence/isolated-lan-8bb57538-20261128.json)
- Windows 从 RC4 维护时经实际端口冲突回滚，释放端口后成功更新同一候选包。保留原配置、观看链接、CA 和卸载器。[维护与回滚](https://github.com/bei612/stream-kit/blob/main/docs/evidence/windows11-hosted-maintenance-8bb57538-20261128.json)

正式版仍需完成独立 Win11 整机重启后的换址验收。现场 Windows 维护和实体平板跨设备换址另行核对。[发布与现场基线](https://github.com/bei612/stream-kit/blob/main/docs/release-status.md)

Windows 首装可使用 `/VERYSILENT /SUPPRESSMSGBOXES /SP- /NORESTART`。首装后在服务器打开 `http://127.0.0.1:9000/`。局域网客户端使用受信 HTTPS，从应用页复制的永久观看链接进入。Android 可导入链接或更新已保存的服务器地址。符合现场 DNS 或 mDNS 条件时，用固定主机名保存入口可适应服务端换 IP。[运维与安装](https://github.com/bei612/stream-kit/blob/main/deploy/README.md) · [局域网地址与证书](https://github.com/bei612/stream-kit/blob/main/docs/lan-address-configuration.md)
