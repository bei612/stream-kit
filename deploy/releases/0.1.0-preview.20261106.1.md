## 安装与访问

Windows 可通过安装向导安装，也可在管理员终端执行：

```powershell
.\stream-kit-preview-902798f02d6e-windows-amd64-setup.exe /VERYSILENT /SUPPRESSMSGBOXES /SP- /NORESTART
```

安装程序负责建立自动启动的 `StreamKitOrchestrator` 系统服务及恢复策略，并启用 Sunshine 和媒体网关的自动启动。控制服务随系统启动；渲染工作进程等待所配置用户的桌面会话，不启用 Windows 自动登录，也不自动重启系统。虚拟录音端点由统一安装流程提供，不依赖 VB-CABLE。部署主机无需安装 Node.js、npm、编译器或单独音频设备工具。

Ubuntu 24.04 使用实际运行图形与音频会话的用户名替换 `RENDER_USER`：

```sh
sudo bash stream-kit-preview-902798f02d6e-ubuntu24.04-amd64-setup.run --user RENDER_USER
```

尚未登录图形桌面时可加 `--no-start`；安装仍会启用用户服务，登录后由用户服务管理器启动。系统运行库通过 Ubuntu 软件源安装。

本机默认管理入口为 `http://127.0.0.1:9000`。其他设备应使用服务器可达的局域网地址；不能使用对方设备自己的 `127.0.0.1`。凭据配置、监听范围、端口和数据保留规则见 [Windows 部署说明](https://github.com/bei612/stream-kit/blob/902798f02d6e5746e9237d5ab92867a6496818bd/deploy/windows/README.md)及 [Ubuntu 安装说明](https://github.com/bei612/stream-kit/blob/902798f02d6e5746e9237d5ab92867a6496818bd/deploy/linux/INSTALL.md)。已有部署不会因为下载新包自动升级；原位升级能力不在本版已验证范围。

## Android 客户端

[Android 0.1.0-preview.20261106.5 下载](https://github.com/bei612/stream-kit/releases/tag/v0.1.0-android-preview.20261106.5)单独提供签名 APK，源码为 `04e5cea5ba30a13af6bee01d25d6347be0aaed08`。App 接入同一管理平台和媒体网关，不直接绕过平台连接 Sunshine。

Android release App 要求证书有效的 HTTPS 永久观看链接；默认 HTTP 服务入口不能直接用于该 App。局域网部署需要配置带正确主机名或 IP SAN 的证书，并使客户端信任其签发 CA。支持 mDNS 且允许组播的同一局域网可使用 `主机名.local` 保持入口名称稳定；数字 IP 书签不会在 DHCP 变化后自动改写。名称解析不代替证书验证。

已发布 APK 在官方模拟器上验证了共享程序画面、程序音播放、客户端麦克风到服务器录音端点及 Web 观看端、持续音源撤权隔离、断网恢复与前后台录音释放。这些证据来自注明版本的既有服务端及隔离测试环境，不等同于本安装包的完整媒体验收，也不代表手机真机性能。

## 校验和交付边界

下载页同时提供两个安装清单、SHA-256 和源码 SBOM。版本、来源、签名驱动清单及散列以相应安装清单为准。发布流程仅接受同源码的完整构建产物，并要求 Windows 实际安装、自启动、原生音频端点和卸载检查匹配该安装文件的散列；Linux 包执行实际载荷提取、初始化、自启动配置和数据保留检查。服务重启检查不等同于整机重启验收。

安装包不包含 Example、UE 测试工程、音频探针、合成音源、模拟器、测试 CA 或测试凭据。Example 仍可从源码单独构建。

尚待完成的部署验收包括：Android 有效输入与撤权后的输入隔离、正式局域网可信 HTTPS 切换，以及实际服务器 IP 改变后的恢复。发布不会改动现有演示机安装、网络或证书信任，也不将这些待验收项标记为已完成。
