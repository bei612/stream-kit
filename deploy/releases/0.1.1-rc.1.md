## 安装与访问

1. Windows 安装器支持 `/VERYSILENT /SUPPRESSMSGBOXES /SP- /NORESTART`。安装系统服务需要管理员权限。首次安装后在服务端打开 `http://127.0.0.1:9000/`。返回 `3010` 时在维护窗口手动重启并登录配置的桌面用户。
2. Ubuntu 使用 `sudo bash INSTALLER.run --user RENDER_USER`，替换下载的文件名和实际桌面用户。
3. 需要跨设备访问时，先部署局域网 HTTPS，让客户端信任部署 CA。登录管理页、登记应用并复制永久观看链接。Web 直接打开链接，Android 在 App 中导入。
