# Stream Kit 0.1.0-preview.20261104.1

本预览版修复安装器自启动配置、Windows 登录等待以及管理页面应用状态同步。源码固定为 `05baccd8aad19a32f427eeabadbc918866e882dd`；Windows x64 和 Ubuntu 24.04 amd64 各提供一个统一安装文件，包含单管理员管理服务、管理页面、Sunshine 和 Web/PWA 媒体网关。

## 本版变化

- Windows 安装器自身注册自动启动的 `StreamKitOrchestrator` 服务，配置故障恢复并核对启动类型。Sunshine 与媒体网关由该服务自动管理，无需安装后手工补启动项。
- 主服务随 Windows 启动；渲染用户尚未登录时，组件等待其活动桌面会话。登录后按用户身份选择会话，不固定沿用上次开机的会话编号。安装器不设置 Windows 自动登录。
- Linux 即使使用 `--no-start` 安装，也会启用用户服务自启动；无需已有用户总线，也无需安装后手工执行启用命令。渲染运行仍需要指定用户的桌面和音频会话。
- 应用列表和详情页统一使用服务端生命周期状态。未完成的停止操作保持可见，失败可重试；完成停止后恢复参数编辑。
- 应用操作等待服务端状态刷新后解锁，避免重复操作；过期查询不会覆盖新状态，后台刷新保留未保存的表单内容。

## 安装与访问

Windows 支持向导与静默安装。在管理员终端将文件名替换为下载的 EXE：

```powershell
.\INSTALLER.exe /VERYSILENT /SUPPRESSMSGBOXES /SP- /NORESTART
```

系统 UAC 仍适用，安装器不自动重启电脑。默认程序目录为 `C:\Program Files\StreamKit`，数据目录为 `C:\ProgramData\StreamKit`。静默安装生成唯一管理员凭据，保存在受保护的 `orchestrator.json` 的 `server.username` 和 `server.password`；使用向导可设置管理员凭据。

Ubuntu 24.04 使用实际渲染桌面的非 root 用户替换 `RENDER_USER`：

```sh
sudo bash INSTALLER.run --user RENDER_USER
```

默认管理入口为 `http://127.0.0.1:9000/`，首次安装仅监听本机。局域网访问需要配置监听地址、防火墙和客户端信任的 HTTPS。其他设备使用服务器局域网地址访问，并从该入口复制观看链接；保存的数字 IP 书签不会随 DHCP 地址变化而自行改写。远程浏览器麦克风需要可信 HTTPS 和录音授权。

客户机器无需另行安装 Node.js、npm 或编译工具。安装包包含开源虚拟音频实现，不依赖 VB-CABLE；Example、UE5 探针、合成录音准备及验收脚本均不进入生产安装内容。目标录音程序需选择对应输入设备。

## 验证结果与边界

[同源码产品构建](https://github.com/bei612/stream-kit/actions/runs/41818329279) 已通过，包含两个平台的安装包和源码 SBOM。[Windows 隔离安装验收](https://github.com/bei612/stream-kit/actions/runs/41828402371) 使用本次实际 EXE，通过静默安装、管理员登录、安装后自动启动配置检查、144,000 帧原生 PCM 收发、网关重启、完整服务重启和卸载。音频零丢帧、零 xrun；重启后服务仍为自动启动，卸载保留运行数据。验收过程中未手工补充平台自启动配置。

Linux 安装包通过实际载荷提取、离线用户服务自启动、三个组件初始化、配置校验及已有数据保护检查。源码同版本的 Windows/Linux 控制服务、媒体网关和 Chromium、Firefox、WebKit 管理页面检查已通过。[详细交付证据](https://github.com/bei612/stream-kit/blob/main/docs/evidence/unified-installers-05baccd8.json) 记录版本、校验值与验收范围。

- 这是预览发布，不能视为全部生产验收完成。Windows 安装检查使用隔离 Windows Server 2022，服务重启不等同于整机重启。
- Windows 安装器用于首次安装，拒绝覆盖已有程序、数据或服务；尚不提供原位升级。不能直接用它覆盖现有部署。
- 真人物理麦克风讲话验收暂缓，合成 PCM 不替代真人语音结果；本轮不包含 Linux 或手机真机验收。
- 已接受的四小时、20 客户端稳定性结果继续保留，未重复长测。Windows 安装器没有商业发行者证书签名；附带内核驱动签名已核验。
- 本次发布本身不修改已部署机器的程序、配置或服务。Windows 应用捕获及 Linux X11 应用隔离保留原有支持范围，不宣称纯 Wayland 环境具备同等能力。

下载文件的精确 SHA-256 分别见随附 `SHA256SUMS.txt` 和 `Linux-SHA256SUMS.txt`。
