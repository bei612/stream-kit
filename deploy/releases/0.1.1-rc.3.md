# 云端渲染 0.1.1 RC3

本预发布提供 Windows 11 x64 安装器、Ubuntu 24.04 amd64 安装器和原生 Android 签名 APK。三个安装包对应源码 `8f5a078e39c070c8b358b456df7fee3c2e437203`。Android `versionCode` 为 `1000032`。

## 本版变化

- Windows 虚拟音频端点保留系统原有的播放、通信播放、录音和通信录音默认设备。录音应用仍可显式选择虚拟麦克风。独立 Windows 验收覆盖了设备重新接入、端点身份保持和 144,000 帧显式录音，零丢帧。[Windows 音频专项](https://github.com/bei612/stream-kit/actions/runs/46062127067)
- Windows 原始安装包通过托管环境的静默安装、服务与媒体网关重启、卸载及数据保留。升级旧版录音策略后，实际端口冲突触发回滚，原策略、服务、永久观看链接、CA 和私钥均已恢复。[托管安装](https://github.com/bei612/stream-kit/actions/runs/46067517275) · [维护回滚](https://github.com/bei612/stream-kit/actions/runs/46067587107)
- 原生 Android 从 `v0.1.0` 覆盖升级后可直接打开原书签。Android 与 Web 共享一条串流，管理端可实时移交和撤销控制权。输入、录音权限拒绝、前后台切换及断线重连已通过验收。[Android 与 Web 验收](https://github.com/bei612/stream-kit/actions/runs/46063575777)
- Win11 与 Android 模拟器联验中，获得控制权的 Android 客户端可将麦克风同时送到目标录音和 Web。撤回控制权后，麦克风静音，Example 程序声音继续播放。[同源音频验收](https://github.com/bei612/stream-kit/blob/main/docs/evidence/windows11-android-packaged-audio-8f5a078e-20261128.json)
- 隔离 Ubuntu 局域网实测更换服务器 IP 后，两端 HTTPS 证书在 9.632 秒内更新，固定主机名下的原观看页无需刷新即恢复直连画面和声音。部署 CA 与观看身份保持。[局域网换址验收](https://github.com/bei612/stream-kit/actions/runs/46063579693)
- 单个应用包的上传和解压上限分别默认 50 GiB，可独立配置。已有 Windows 环境完成了 26 GiB 应用包实测。[应用包与磁盘预算](https://github.com/bei612/stream-kit/blob/main/docs/user-guide.md#上传程序包)

干净 Win11 的首装与整机重启已通过，三个组件均在重启后自动恢复。首装、重启和卸载后，四个原有音频默认设备均得到保留。正式交付还需现场维护验证，以及用独立设备确认 Windows 换址后的视频、声音及控制恢复。[Win11 首装与重启验收](https://github.com/bei612/stream-kit/actions/runs/46067583718)

## 安装与访问

1. 在 Windows 服务端运行安装器。静默安装参数为 `/VERYSILENT /SUPPRESSMSGBOXES /SP- /NORESTART`。安装返回 `3010` 时，重启后核对服务和音频设备。新安装默认从服务端打开 `http://127.0.0.1:9000/`。
2. 在 Ubuntu 执行 `sudo bash INSTALLER.run --user RENDER_USER`，按实际文件名和渲染桌面用户名替换参数。
3. 跨设备使用局域网 HTTPS。客户端信任本部署 CA 后，从管理页复制应用的永久观看链接。Web 可直接打开，Android 可在 App 中导入。采用固定主机名时，地址变化后客户端通过局域网 DNS 或 mDNS 重新解析。[局域网地址与证书](https://github.com/bei612/stream-kit/blob/main/docs/lan-address-configuration.md)

下载附件包含各平台 SHA‑256 校验表、构建清单、许可证和软件物料清单。现场安装版本、适用的验证范围及既有部署维护要求见发布基线。[使用文档](https://github.com/bei612/stream-kit/blob/main/docs/README.md) · [发布与部署基线](https://github.com/bei612/stream-kit/blob/main/docs/release-status.md)
