# 云端渲染 0.1.1 RC3

本预发布提供 Windows 11 x64 单安装器、Ubuntu 24.04 amd64 单安装器和原生 Android 签名 APK。三个安装包对应同一源码 `439f2a06376ba8363c1318c0d6e3d72b3ef45729`。Android `versionCode` 为 `1000031`。

## 本版修复与验收

- Windows 服务停机时先让媒体网关完成音频设备释放。用原始安装包在托管 Windows 上实测静默安装、网关与服务重启、端口冲突回滚和卸载。回滚后原观看链接和部署身份继续可用。卸载后四个默认音频角色恢复安装前状态，运行数据保留。[安装](https://github.com/bei612/stream-kit/actions/runs/46057599330) · [回滚与卸载](https://github.com/bei612/stream-kit/actions/runs/46057619546)
- Win11 搭配官方 Android 模拟器，使用原始发布组件和签名 APK 验证程序画面、程序声以及麦克风回传。Web 和 Android 共用一条上游，获得控制权的 Android 客户端可把麦克风同时送到目标录音端点和 Web。撤权后麦克风静音，程序声保持。覆盖旧版本 APK 升级、永久链接复用、输入交接、权限拒绝和断线恢复。[音频联验](https://github.com/bei612/stream-kit/blob/main/docs/evidence/windows11-android-packaged-audio-439f2a06-20261128.json) · [Android 端到端验收](https://github.com/bei612/stream-kit/actions/runs/46055204729)
- Ubuntu 隔离局域网中实际更换服务器 IP 后，管理端和媒体入口自动更新证书，固定主机名下的原观看页恢复直连媒体，部署 CA 和观看身份保留。现场 Win11 换址及独立设备恢复另行验收。[局域网换址验收](https://github.com/bei612/stream-kit/actions/runs/46055208430)
- 应用包上传和解压分别默认上限 50 GiB，可独立配置。Windows 实际导入过 26 GiB 应用包。同一数据卷需为上传暂存、解压后的程序和系统预留留出空间。[应用包和磁盘预算](https://github.com/bei612/stream-kit/blob/main/docs/user-guide.md#上传程序包)

## 安装与访问

1. Windows 可使用 `/VERYSILENT /SUPPRESSMSGBOXES /SP- /NORESTART` 静默安装。安装系统服务需要管理员权限。首次在服务端访问 `http://127.0.0.1:9000/`。若安装返回 `3010`，重启后核对服务及音频设备状态。
2. Ubuntu 执行 `sudo bash INSTALLER.run --user RENDER_USER`，将文件名和桌面用户名替换为实际值。
3. 跨设备访问使用局域网 HTTPS，客户端信任本部署的 CA 后，从管理页复制应用的永久观看链接。Web 可直接打开，Android 可在 App 中导入。数字 IP 书签换址后可修改连接地址，配置固定主机名的客户端可按现场 DNS 或 mDNS 重新发现服务。
