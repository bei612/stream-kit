# Stream-Kit 统一安装候选版 2026-11-01.3

[下载安装包、校验清单和源码 SBOM](https://github.com/bei612/stream-kit/releases/tag/v0.1.0-preview.20261101.3)

Windows x64 和 Ubuntu 24.04 amd64 每个平台各提供一个安装文件，均来自干净提交 `9fe6979a63a802b31c81b8429b5317e50e3ec4c4`。包含统一管理服务及页面、Sunshine 渲染端、原生 Web/PWA 媒体网关；Windows 同时包含音视频测试程序。安装和运行不需要宿主机安装 Node.js/npm、Go、Rust 或 CMake。

本版补齐 Windows 网关和音频探针的应用本地 Microsoft 运行库，保留原始签名、许可证说明和文件清单，支持在没有全局 Visual C++ 运行库的宿主机部署。Linux 新增单文件安装器，保留原生 bin/lib/share 目录、私有 Vulkan loader 和许可证；上传应用支持原生 ELF 或 Unix 启动脚本，选择上传入口时只赋予该文件属主执行权限，已有本机程序权限保持原样。

## 安装

Windows 使用管理员终端执行：

```powershell
.\stream-kit-preview-9fe6979a63a8-windows-amd64-setup.exe /VERYSILENT /SUPPRESSMSGBOXES /SP- /NORESTART
```

默认管理入口为 `http://127.0.0.1:9000`。管理员从 `C:\ProgramData\StreamKit\orchestrator.json` 读取 `server.username`、`server.password`；指定其他数据目录时使用对应位置。安装器支持向导和静默模式，Windows UAC 仍适用，不自动重启。已有部署不会被覆盖，暂不支持原位升级。端口、会话身份和凭据文件参数见 [Windows 部署说明](https://github.com/bei612/stream-kit/blob/main/deploy/windows/README.md)。

Ubuntu 24.04 使用实际桌面/音频会话用户替换 `RENDER_USER`：

```sh
sudo bash stream-kit-preview-9fe6979a63a8-ubuntu24.04-amd64-setup.run --user RENDER_USER
```

系统运行库由 apt 解析；没有桌面会话时加 `--no-start`，登录后启动用户服务。数据位于该用户的 `~/.local/share/stream-kit/runtime`，初始管理入口同上。详见 [Linux 部署说明](https://github.com/bei612/stream-kit/blob/main/deploy/linux/README.md)。远程浏览器采集麦克风需要 HTTPS 和浏览器授权。
