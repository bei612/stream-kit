# Stream-Kit 统一运行安装候选版 2026-11-01.4

[下载安装包与 SHA-256 清单](https://github.com/bei612/stream-kit/releases/tag/v0.1.0-preview.20261101.4)

Windows x64、Ubuntu 24.04 amd64 各提供一个安装文件，均由干净提交 `279bac98f38d6f4437632c2d3b94f9c47780b27d` 构建。安装内容只有统一管理服务及页面、原生 Web/PWA 媒体网关、Sunshine 和它们必需的运行库。安装及运行无需在宿主机安装 Node.js/npm、Go、Rust、CMake 或 UE 编辑器。

本版移除 Windows 客户安装器中的棋盘及音频探针、示例快捷方式。两个平台共用安装载荷规则，拒绝混入示例、测试目录、Playwright、开发工具及测试配置；安装清单均声明 `payload_profile: runtime`。源码中的 `example/` 和 UE5 录音验收工程仍供开发者单独构建，不进入客户安装包。历史预发布包的内容保持原记录。

## 安装与访问

Windows 在管理员终端静默安装：

```powershell
.\stream-kit-preview-279bac98f38d-windows-amd64-setup.exe /VERYSILENT /SUPPRESSMSGBOXES /SP- /NORESTART
```

默认管理地址为 `http://127.0.0.1:9000`。管理员凭据保存在受保护的 `C:\ProgramData\StreamKit\orchestrator.json` 的 `server.username`、`server.password`。Windows UAC 仍适用，不自动重启；已有部署不会被覆盖，暂不支持原位升级。端口、凭据文件、指定 Windows 会话等参数见 [Windows 部署说明](https://github.com/bei612/stream-kit/blob/main/deploy/windows/README.md)。

Ubuntu 使用实际桌面和音频会话用户替换 `RENDER_USER`：

```sh
sudo bash stream-kit-preview-279bac98f38d-ubuntu24.04-amd64-setup.run --user RENDER_USER
```

没有桌面会话时加 `--no-start`，登录后启动用户服务。系统运行库由 apt 解析，数据位于该用户的 `~/.local/share/stream-kit/runtime`。详见 [Linux 部署说明](https://github.com/bei612/stream-kit/blob/main/deploy/linux/README.md)。客户端使用浏览器；远程麦克风需要 HTTPS 和浏览器授权，不需要客户端驱动。

当前安装包不附带虚拟音频驱动。向通用录音机或 UE5 投递客户端麦克风，服务器需要兼容的专用输出/录音端点对；管理页按端点选择，不限定 VB-CABLE，不要求客户购买 VB-CABLE。端点是服务器运行能力，开发探针则是验收工具，两者不能混为一谈。

仍未闭合的核心交付项是：无需绑定付费产品的服务器虚拟录音端点自动部署，以及真实客户端语音到目标程序和旁观者的完整验收。免费开源驱动候选已通过微软内核签名校验，但尚未形成集成音频设备，未随本版分发。该候选的 [核验记录](https://github.com/bei612/stream-kit/blob/main/docs/evidence/free-virtual-audio-provider-review-20261101.json) 与 [安装包交付记录](https://github.com/bei612/stream-kit/blob/main/docs/evidence/unified-installers-279bac98.json) 分别保留其实际范围。因此保持预发布，不声称生产目标全部完成。商业发行者证书、Linux/手机真机和 24 小时长测按已确认范围排除。
