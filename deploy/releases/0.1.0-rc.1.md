# Stream-Kit 0.1.0-rc.1

本候选版提供 Windows x64 和 Ubuntu 24.04 amd64 各一个统一安装文件，包含单管理员管理服务及页面、Sunshine 渲染端和 Web/PWA 媒体网关。客户端通过浏览器观看、接收声音和使用管理员授予的唯一控制权，无需安装原生客户端。

Windows 安装包集成开源虚拟音频控制器及运行实现，服务器可将授权客户端的麦克风送入指定录音程序或 UE5，同时向观看客户端广播程序音和麦克风混音。无需购买或安装 VB-CABLE。管理页配置目标音频端点，目标程序选择对应录音输入；安装器不会替目标程序更改录音设置。

产品安装内容仅包括运行组件、必要运行库与许可证。棋盘示例、录音探针、UE5 验收工程、浏览器自动化和测试配置留在源码开发目录，不随安装包交付。安装及运行无需在宿主机安装 Node.js/npm、Go、Rust、CMake 或 UE 编辑器。

## 安装与访问

下载后先按随附 SHA-256 清单核对安装文件。Windows 在管理员终端执行，将 `INSTALLER.exe` 替换为实际文件名：

```powershell
.\INSTALLER.exe /VERYSILENT /SUPPRESSMSGBOXES /SP- /NORESTART
```

Windows UAC 仍适用；安装器不绕过系统授权、不更改录音隐私设置、不自动重启。程序位于 `C:\Program Files\StreamKit`，数据位于 `C:\ProgramData\StreamKit`。初始化生成唯一管理员凭据，保存在受保护的 `orchestrator.json` 的 `server.username`、`server.password`，不采用共享默认密码。默认管理地址为 `http://127.0.0.1:9000`。

Ubuntu 24.04 使用实际拥有桌面与音频会话的非 root 用户替换 `RENDER_USER`：

```sh
sudo bash INSTALLER.run --user RENDER_USER
```

Ubuntu 安装器通过系统包管理器补齐运行库，需要访问相应软件源。无图形会话时可加 `--no-start`；渲染运行仍需要该用户的桌面及 PulseAudio 或 PipeWire-Pulse 服务。数据与管理员配置位于该用户的 `~/.local/share/stream-kit/runtime`。

初始监听仅限本机。远程访问需在管理页配置监听、公开媒体地址及可信 HTTPS；浏览器麦克风仍需客户端主动授权。Windows 目标账户还需允许桌面应用访问录音设备。

## 运行与更新边界

- Windows 服务在媒体网关启动前准备自身虚拟音频设备，后续启动复用配置；首次未准备的设备枚举期间，Windows 可能短暂改变默认输出。准备完成后的虚拟输出不参与系统和通信默认输出选择，应用内仍可按端点明确路由。
- Windows 安装器拒绝覆盖已有程序目录、数据目录或服务注册，目前不提供原位升级。卸载保留运行数据；更新前备份数据并按部署说明迁移。
- Windows 安装器未使用商业发行者证书签名。附带内核驱动使用经校验的签名包，不启用测试签名或降低系统安全策略。
- 真人物理麦克风讲话验收尚未完成。本候选版不将生成 PCM 的链路结果表述为真人语音验收通过；Linux 和手机真机验收不在本轮发布验收范围内。
