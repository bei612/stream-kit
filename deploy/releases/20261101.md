# Windows 统一安装候选版 2026-11-01

[下载页面](https://github.com/bei612/stream-kit/releases/tag/v0.1.0-preview.20261101)

一个 EXE 安装管理服务、Sunshine、浏览器媒体网关及音视频示例。安装和运行不依赖宿主机 Node.js/npm、Go、Rust 或 CMake。默认静默命令：

```powershell
.\stream-kit-preview-a7bf60541a99-windows-amd64-setup.exe /VERYSILENT /SUPPRESSMSGBOXES /SP- /NORESTART
```

安装凭据、默认入口、端口覆盖及卸载说明见 [Windows 部署说明](../windows/README.md)。安装只需 Windows 本身的 UAC 提权；已安装服务的正常运行不需要反复安装或提权。
