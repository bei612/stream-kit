# 云端渲染 0.1.1

本版提供一个 Windows 11 x64 服务端安装器和一个原生 Android 客户端。两件产物使用同一份源码 `ce49050f4dfcbd1e22d9d4f22093f6b965e6aac8`。同一个应用串流可以供 Web 和 Android 一起观看，管理员可实时移交或收回操作与麦克风权限。

## 本版改进

- 局域网地址变化后，服务沿用已有部署 CA 更新管理端和媒体网关的 HTTPS 身份。直连的受管 WebRTC 会话使用信令连接实际到达的 IPv4 地址承载媒体。启用固定观看主机名后，服务器换 IP 时，能解析并访问该主机名的设备继续使用原链接。已有数字 IP 的书签可一次换成固定主机名并保留观看密钥。已配置固定 NAT 映射的部署继续使用原映射。
- 应用详情的永久观看链接操作和采集能力说明随管理端语言切换。上传直接写入暂存文件，60 秒无数据才会超时。添加应用页面显示服务器当前生效的单包和解压总量上限，默认为 50 GiB 和 50 GiB。

## 安装与访问

1. **服务端**：运行 `stream-kit-0.1.1-ce49050f4dfc-windows-amd64-setup.exe`。静默安装参数为 `/VERYSILENT /SUPPRESSMSGBOXES /SP- /NORESTART`，安装系统服务需要 Windows 管理员权限。控制服务随 Windows 启动，媒体网关及 Sunshine 随可用的 Windows 桌面会话恢复。
2. **管理后台**：全新安装后先在服务端打开 `http://127.0.0.1:9000/`。需要从其他设备访问时，先按局域网配置文档启用 HTTPS、让客户端信任部署 CA，再用服务端当前 LAN IP 访问 `9000` 端口。登录后在「应用管理」登记程序，在应用详情复制永久观看链接。
3. **Android 客户端**：安装 `stream-kit-android-0.1.1.apk`（versionCode `1000024`），导入永久观看链接即可启动。沿用云端渲染既有发行签名。Web 客户端可直接打开同一链接。在「渲染会话」授予控制权后，客户端可操作画面并按需打开麦克风。

已在官方 Android 36 模拟器验证从正式 `v0.1.0` 直接覆盖升级，并通过原书签启动串流。[Android 升级记录](https://github.com/bei612/stream-kit/actions/runs/45950069635)

下载页的 `SHA256SUMS.txt` 覆盖 Windows 安装器、构建清单和 SPDX 源码依赖清单。`Android-SHA256SUMS.txt` 覆盖 APK、构建来源、依赖清单及许可证分发包。一台渲染宿主机同时服务一个渲染应用。对既有 Windows 部署进行维护前，请保留应用数据、配置和部署 CA。Ubuntu 服务端可从既有 [Ubuntu 发布页](https://github.com/bei612/stream-kit/releases/tag/v0.1.0) 下载。

访问、维护、兼容性和对应版本证据见[使用文档](https://github.com/bei612/stream-kit/blob/main/docs/README.md)、[局域网地址配置](https://github.com/bei612/stream-kit/blob/main/docs/lan-address-configuration.md)和[发布基线](https://github.com/bei612/stream-kit/blob/main/docs/release-status.md)。
