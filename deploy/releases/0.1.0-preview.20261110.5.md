Stream Kit 管理端状态与接口契约修复预发布版，运行源码 `91f87d34143f064867407f9ffdf2c65ab1b32643`。

本次改动统一管理 API 类型和响应外层校验，日志翻页使用服务器总数，上传与普通请求一致处理登录过期。参数编辑、查询刷新和固定观看入口按各自生命周期接收结果，防止晚到响应覆盖后续操作；上传成功后直接进入服务器返回的实际应用详情。全量前端 TypeScript、ESLint、生产构建及跨平台源码 CI 已通过。
