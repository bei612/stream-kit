# 云端渲染 0.1.1 RC4

本预发布提供 Windows 11 x64、Ubuntu 24.04 amd64 安装器和原生签名 Android APK。三个产物来自源码 `bb3c8d24a7a0a33c090ef9e60e555a7b081058b9`。Android `versionCode` 为 `1000033`。

## 连接与验收

- Android 在系统无法解析已保存入口的 `.local` 主机名时，可在当前局域网上通过 Sunshine 的 DNS‑SD 广播查找同名地址，并使用原主机名校验 TLS。实体平板覆盖安装后改用固定主机名，保留原观看密钥与部署 CA，重启 App 后仍能启动 Example。[平板验证与截图](https://github.com/bei612/stream-kit/blob/main/docs/evidence/windows11-tablet-mdns-signed-20261128.json)
- Android 与 Web 已验证共享同一原生串流、实际目标键鼠、控制权交接与撤权、从 `v0.1.0` 覆盖升级、录音权限拒绝和断网恢复。Windows 官方模拟器联验确认麦克风同时送达目标录音与 Web，撤权后麦克风静音，程序音继续播放。[客户端控制验收](https://github.com/bei612/stream-kit/actions/runs/46130439407) · [Windows 音频验收](https://github.com/bei612/stream-kit/blob/main/docs/evidence/windows11-android-packaged-audio-bb3c8d24-20261128.json)
- Windows 原始安装包通过托管静默安装、服务与网关重启、默认音频端点保护和卸载。RC3 在实际端口冲突后回滚，移除冲突后成功换用 RC4 三组件。原配置、观看链接、部署 CA、私钥及卸载器均得到保留。[托管安装](https://github.com/bei612/stream-kit/actions/runs/46131762858) · [受控维护](https://github.com/bei612/stream-kit/actions/runs/46132098533)
- Ubuntu 隔离局域网实际更换服务器 IPv4 后，两个 HTTPS 入口在 9.326 秒内更新证书，固定主机名下的原观看页无需刷新即恢复直连。部署 CA 和组件进程保持。[换址验收](https://github.com/bei612/stream-kit/actions/runs/46130440167)

正式交付还需 RC4 的独立 Win11 整机重启验收、现场 Windows 维护，以及使用独立设备确认现场服务器真实换址后的串流恢复。[发布与部署基线](https://github.com/bei612/stream-kit/blob/main/docs/release-status.md)

## 安装与访问

1. Windows 首次安装可运行安装器，或附加 `/VERYSILENT /SUPPRESSMSGBOXES /SP- /NORESTART`。新装后从服务器打开 `http://127.0.0.1:9000/`。安装返回 `3010` 时，整机重启后核对服务和音频准备。已有部署按运维手册走维护流程。
2. Ubuntu 在渲染服务器执行 `sudo bash INSTALLER.run --user RENDER_USER`，将文件名和桌面会话用户名替换成实际值。
3. 跨设备请使用受信任的 HTTPS。客户端信任部署 CA 后，从应用管理复制永久观看链接。Android 可导入链接，或在「修改服务器地址」保留已有应用密钥。数字 IP 链接在宿主机改址后需更新地址。局域网能解析并访问固定主机名时，可继续使用原主机名链接。

附件包含 SHA-256、平台清单、许可说明和软件物料清单。[安装与运维](https://github.com/bei612/stream-kit/blob/main/deploy/README.md) · [局域网地址与证书](https://github.com/bei612/stream-kit/blob/main/docs/lan-address-configuration.md)
