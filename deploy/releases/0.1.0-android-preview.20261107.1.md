# Stream Kit Android 0.1.0-preview.20261107.1

修复首次启动等待时间不足的问题：打开永久应用链接时允许服务端完成渲染端自动配对和观看准入，最长等待 60 秒。连接后的心跳、控制权和麦克风权限仍使用原有短时限。
