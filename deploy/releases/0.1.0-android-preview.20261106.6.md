# Stream Kit Android 0.1.0-preview.20261106.6

修复 Android 官方键盘翻译器与受管网关之间的键码格式差异：将上游 `0x80` 前缀转换为网关和 Web 共用的虚拟键码；按下、释放、修饰键及控制权校验保持一致。非法键码不发送。

下载 `stream-kit-android-0.1.0-preview.20261106.6.apk` 安装。使用管理员提供的 HTTPS 永久应用链接；私有局域网 CA 通过 Android 系统设置安装。APK 保持原项目签名，版本号为 `1000006`。

验证：Android CI、13 项 release JVM 测试、发布清单检查、压缩后原生 JNI 模拟器检查均通过；下载候选的 21 项 SHA-256 校验及 APK 签名通过，已安装到本机官方 Android API 36 模拟器。

此版本仍为预览版：本机 Windows 端已收到修复后的 Android 和 Web 按键，但目标程序的实际响应仍未通过验收，正在定位宿主端输入问题；不能将协议修复或控制权状态切换视为端到端输入通过。正式 LAN HTTPS 部署及实际宿主机 IP 变化恢复仍待完成。此前的程序音、麦克风撤权和重连证据属于 `.5` 版本，本次没有重复音频验收。
