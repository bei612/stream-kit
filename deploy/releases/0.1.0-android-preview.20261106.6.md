# Stream Kit Android 0.1.0-preview.20261106.6

修复 Android 官方键盘翻译器与受管网关之间的键码格式差异：将上游 `0x80` 前缀转换为网关和 Web 共用的虚拟键码；按下、释放、修饰键及控制权校验保持一致。非法键码不发送。

下载 `stream-kit-android-0.1.0-preview.20261106.6.apk` 安装。使用管理员提供的 HTTPS 永久应用链接；私有局域网 CA 通过 Android 系统设置安装。APK 保持原项目签名，版本号为 `1000006`。

验证：Android CI、13 项 release JVM 测试、发布清单检查、压缩后原生 JNI 模拟器检查均通过；下载候选的 21 项 SHA-256 校验及 APK 签名通过，已安装到本机官方 Android API 36 模拟器。

补充验收（2026-11-07）：复用此处发布的同一份 APK 与已发布的 d36cead6 Linux 服务端，在官方 Android API 36 模拟器中通过 Android/Web 联合输入验收。两端共享一个上游；目标程序实际收到 Android 按键和触摸、移交后的 Web 按键和点击；撤销后输入无效，重新授权后恢复。目标程序正常停止，渲染端返回空闲。验收使用 720p/30fps，不代表真机性能或本机 Windows 环境的输入问题已解决。

验收：[完整 CI 记录](https://github.com/bei612/stream-kit/actions/runs/42253644366)、[事件计数与适用范围](https://github.com/bei612/stream-kit/blob/629db277/docs/evidence/android-stream-input-20261107.json)。测试观察器和测试 CA 仅用于独立 CI，不在正式 APK 或安装包内。

此版本仍为预览版：本机 Windows 环境的输入问题仍未查明；正式 LAN HTTPS 部署及实际宿主机 IP 变化恢复仍待完成。此前程序音、麦克风撤权和重连证据属于 `.5` 版本，本次没有重复音频验收。此更新只补充发布说明，APK、签名、版本号与下载校验值均未改变。
