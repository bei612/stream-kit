# Stream-Kit 0.1.0-rc.2

本候选版将永久应用启动链接、局域网访问修复和原生媒体网关静态资源修复纳入统一安装文件。产品源码固定为 `66249387b32975e79d56b19fdf98d4bc7d414da0`。Windows x64 和 Ubuntu 24.04 amd64 各提供一个安装文件，包含单管理员管理服务及页面、Sunshine 渲染端和 Web/PWA 媒体网关。

## 本版变化

- 应用详情页在应用尚未运行时即可启用、查看和复制永久观看链接。打开链接自动唤起对应应用，并使用后台保存的启动参数进入串流；已运行的应用加入现有共享会话。
- 永久链接没有两分钟有效期。刷新、重启服务不会改变地址；管理员可以重置或停用。重置后旧链接不能再进入，已经连接的客户端需另行断开。
- 永久链接只授予观看入口，不授予管理权限或控制权。输入和麦克风仍由唯一控制者授权约束，内部媒体凭据继续采用短时票据。
- 浏览器控制地址跟随实际访问的主机，避免局域网客户端被导向自身的 `127.0.0.1`。媒体网关使用原生程序旁的 `dist` 资源目录，修复安装布局下的观看页面访问。

Windows 安装包集成开源虚拟音频控制器及运行实现，不依赖 VB-CABLE。生产安装内容仅包括运行组件、必要运行库和许可证；Example、录音探针、UE5 验收工程及测试脚本均不随包安装。安装和运行无需宿主机另行安装 Node.js/npm、Go、Rust、CMake 或 UE 编辑器。

## 安装与访问

下载后按随附 SHA-256 清单核对文件。Windows 在管理员终端执行，将 `INSTALLER.exe` 替换为实际文件名：

```powershell
.\INSTALLER.exe /VERYSILENT /SUPPRESSMSGBOXES /SP- /NORESTART
```

Windows UAC 仍适用，不自动重启电脑。程序位于 `C:\Program Files\StreamKit`，数据位于 `C:\ProgramData\StreamKit`。首次安装生成唯一管理员凭据，保存在受保护的 `orchestrator.json` 的 `server.username`、`server.password`；交互式安装也可设置管理员。默认本机管理入口为 `http://127.0.0.1:9000/`，服务配置为开机自动启动。

Ubuntu 24.04 使用拥有桌面与音频会话的非 root 用户替换 `RENDER_USER`：

```sh
sudo bash INSTALLER.run --user RENDER_USER
```

Ubuntu 安装器通过系统包管理器补齐运行库，需要访问对应软件源。无图形会话时可加 `--no-start`；渲染运行仍需要该用户的桌面和 PulseAudio 或 PipeWire-Pulse 服务。数据位于该用户的 `~/.local/share/stream-kit/runtime`。

首次安装默认仅监听本机。局域网部署需配置管理服务与媒体网关的监听地址、防火墙和 HTTPS；服务间内部地址可保持回环。其他设备必须使用服务器的局域网地址或可解析主机名访问，并从该入口复制应用链接。保存的数字 IP 链接不会自动跟随 DHCP 变化；固定书签应使用局域网能够解析的稳定主机名，或配置固定地址。

浏览器麦克风需要客户端信任的 HTTPS 和录音授权。无公网域名时也可使用包含主机名或 IP 的证书，但客户端必须信任其签发者；IP 变化后，只有旧 IP 的证书需要更新。iPad 等浏览器可能要求一次点击才能播放声音。

## 适用边界

- 本版仍为 RC 候选版。真人物理麦克风讲话验收暂缓，不能将生成音频的链路结果视为真人语音验收通过。Linux 和手机真机验收不在本轮范围内。
- Windows 安装器用于首次安装，拒绝覆盖已有程序目录、数据目录或服务注册；不提供原位升级。卸载保留运行数据，已有部署应先备份并按部署说明迁移。
- Windows 安装器未使用商业发行者证书签名；附带内核驱动使用经核验的签名包，不启用测试签名。
- 目标录音程序仍需选择对应输入端点，Windows 还需允许桌面应用访问录音设备。首次设备枚举可能短暂改变默认输出；设备准备完成后不参与系统默认输出选择。
- Windows 应用画面捕获和 Linux X11 应用隔离保留原有支持范围，不宣称纯 Wayland 环境具备同等应用捕获能力。

## 验证依据

源码 `66249387` 的 [跨平台 CI](https://github.com/bei612/stream-kit/actions/runs/41756604158) 六项任务全部通过，覆盖 Windows/Linux 控制服务和媒体网关、管理 Web、源码 SBOM。

[已安装 Windows 的永久链接验收](https://github.com/bei612/stream-kit/blob/main/docs/evidence/durable-watch-link-20261104.json) 验证了停止状态下显示链接、无管理员凭据自动唤起并收到实际视频、同一书签刷新后继续观看、旧链接重置失效与新链接可用。该结果来自本机 Chrome，不作为物理 iPad/电视或真人讲话的证据。

此前已接受的四小时、20 客户端稳定性结果继续保留，未重复长测；原记录的组件版本和验收范围不改写为本版新测结果。局域网实际 DHCP 切换和本机可信 HTTPS 切换尚未执行。

[Linux 同版本构建](https://github.com/bei612/stream-kit/actions/runs/41760125211) 已通过 Sunshine 应用捕获检查、原生组件构建及单文件安装包检查。安装包检查覆盖实际载荷提取、三个组件初始化、配置校验及已有数据保护，不包含桌面 GPU 串流真机验收。

Windows 安装包使用已验证的同版本原生组件和官方 Inno Setup 7.1.1 生成，附带内核驱动签名验证通过。[新版整包隔离安装验收](https://github.com/bei612/stream-kit/actions/runs/41762273259) 直接下载本候选版同一 SHA-256 的安装文件，在 Windows Server 2022 中通过首次驱动安装、静默安装、管理员登录、144,000 帧 PCM 收发、网关重启、完整 LocalSystem 服务重启和卸载；音频零丢帧、零 xrun，重启后端点身份保持，卸载保留运行数据。运行器没有预存物理音频端点，不能据此证明已有物理默认设备保持、GPU 串流或真人讲话。测试脚本与合成音频准备只在隔离运行器使用，不进入安装包，也未在本机演示环境执行。
