# Stream Kit 统一服务端预发布版 2026-11-10.3

Windows x64 与 Ubuntu 24.04 amd64 安装包均来自 `40146db2ffa8b15040906cf130be8e89548c48da`，包含管理服务、Sunshine 和媒体网关。发布直接复用已构建、已验收的原始文件，不重新构建，也不会自动更新现有部署。

## 本版修复

- 网关和浏览器不再记录完整 SDP、ICE 候选及动态 ICE 脚本输出，避免媒体凭据进入日志和控制台。
- SDP/RTC 解析失败在应用错误边界丢弃原始输入；错误响应、Display、Debug 和错误链不再保留该输入，原 HTTP 状态不变。
- 保留连接进度、权限通知生命周期和确定终态处理：串流结束后停止输入、麦克风、RTC 与自动恢复，用户可主动重新打开永久链接。

## 安装与访问

Windows 管理员终端静默安装：

```powershell
.\stream-kit-preview-40146db2ffa8-windows-amd64-setup.exe /VERYSILENT /SUPPRESSMSGBOXES /SP- /NORESTART
```

Ubuntu 24.04 将 `RENDER_USER` 替换为实际拥有图形、音频会话的用户：

```sh
sudo bash stream-kit-preview-40146db2ffa8-ubuntu24.04-amd64-setup.run --user RENDER_USER
```

Windows 安装器注册自动启动的 `StreamKitOrchestrator` 系统服务，由其管理渲染端和网关。渲染需要登录后的桌面会话；安装器不设置自动登录、不自动重启电脑。运行不要求宿主机另装 Node.js/npm，不依赖 VB-CABLE。Example、测试声源、探针、开发 CA、测试凭据和调试工具不随安装包交付。

首次在服务器本机打开 `http://127.0.0.1:9000`，从受保护的运行配置取得唯一管理员凭据。局域网客户端使用服务器局域网地址；远程麦克风需配置可信 HTTPS、监听和媒体地址，再从应用页复制永久观看链接。地址更新沿用原部署 CA，保存配置并重启服务生效；数字 IP 书签需要更新地址部分。

本版安装器保护已有安装和数据，不提供通用原位升级。现有部署请参阅 [Windows 部署说明](https://github.com/bei612/stream-kit/blob/main/deploy/windows/README.md)、[Linux 部署说明](https://github.com/bei612/stream-kit/blob/main/deploy/linux/README.md)及[地址配置](https://github.com/bei612/stream-kit/blob/main/docs/lan-address-configuration.md)。Android APK [20261109.6](https://github.com/bei612/stream-kit/releases/tag/v0.1.0-android-preview.20261109.6)独立签名与发布，不包含在服务端安装器中。

## 验收边界

这是预发布版。服务重启不等于整机重启；Windows 音频默认设备基线为空，不外推已有非空默认设备设置。卸载后验证配置文件保留，未单独验证所有应用文件和数据库的保留。

本包的独立部署验收不代表现有本机 Windows 已完成更新或实际宿主机换 IP/重启通过。正式 Android `.6` 已在旧本机 `98e419f7` 部署和官方 Windows 模拟器中通过程序音、合成麦克风到录音端点与 Web 观看端、撤权、权限拒绝及重连/前后台检查；其 [Windows 音频记录](https://github.com/bei612/stream-kit/blob/main/docs/evidence/android-release-audio-windows-20261110.json)与 [生命周期记录](https://github.com/bei612/stream-kit/blob/main/docs/evidence/android-release-lifecycle-windows-20261110.json)分别保留范围，不替代本包的 Android 全链路验收或真人语音、UE 内部录音。Linux 模拟器的近静音失败也保留，未改写为通过。
