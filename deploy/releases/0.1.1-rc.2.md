# 云端渲染 0.1.1 RC2

本次预发布提供 Windows 11 x64 单安装器、Ubuntu 24.04 amd64 单安装器和项目签名的原生 Android APK。三项产物均来自 `66a79e5d11e54a7048fccb042cd93327be92df3b`。Android `versionCode` 为 `1000029`。

## 应用包上传

管理端支持超过 25 GB 的单个应用归档。上传大小和解压总量默认各为 **50 GiB（约 53.7 GB）**，可分别配置。接收数据流式写入暂存目录，管理页显示可用空间。Win11 已在实际应用导入中上传和解压 26 GiB，程序已就绪且入口校验一致。若暂存目录和应用目录在同一卷，需同时留出压缩包、解压结果与磁盘预留空间。[用法与磁盘预算](https://github.com/bei612/stream-kit/blob/main/docs/user-guide.md#上传程序包) · [26 GiB 验收](https://github.com/bei612/stream-kit/blob/main/docs/evidence/windows11-archive-space-666a6a01-20261127.json)

## 安装与访问

1. Windows 安装器支持 `/VERYSILENT /SUPPRESSMSGBOXES /SP- /NORESTART`。安装系统服务需要管理员权限。首次安装后在服务端打开 `http://127.0.0.1:9000/`。经常导入大型应用包时，使用 `/DATADIR` 选择容量充足的数据卷。
2. Ubuntu 使用 `sudo bash INSTALLER.run --user RENDER_USER`，将文件名和桌面用户名替换为现场值。
3. 跨设备访问使用局域网 HTTPS。客户端信任部署 CA 后，在管理页登记应用并复制永久观看链接。Web 直接打开链接，Android 在 App 中导入。
