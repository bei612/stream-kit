# Stream Kit 统一服务端预发布版 2026-11-09.1

Windows x64 和 Ubuntu 24.04 amd64 的单文件安装包均来自源码 `98e419f7f85fa36a92651ee55396815386a233c4`。本版包含管理页、Sunshine 和媒体网关，仍为预发布；发布不会自动更新已有安装。

## 本版变化

- 串流会话按实际渲染实例同步。启动凭据的有效期保护正常接入；已退出的实例释放会话和权限，客户端心跳不能永久维持失败启动，旧实例恢复流程不会停止新实例。
- 管理端分开显示当前会话和只读已结束记录。已结束记录按七天、最多一百条清理；离线连接不显示控制操作。
- 管理端统一展示各客户端和唯一控制权；Web/Android 明确显示控制者或仅观看身份。交接、撤销和过期控制代次由服务端约束。
- 配置 `server.lan_tls` 后，地址变更可在原部署 CA 下更新服务器证书，保持客户端信任。修改服务器配置并重启服务即可应用；数字 IP 书签本身不会自动改写。Android 的服务器地址可在客户端修改，无需重新编译 APK。
- 应用页、配置页和会话页调整布局与反馈，明确保存配置和实际运行配置、即时与重启生效的区别。

## 安装和访问

Windows 管理员终端静默安装：

```powershell
.\stream-kit-preview-98e419f7f85f-windows-amd64-setup.exe /VERYSILENT /SUPPRESSMSGBOXES /SP- /NORESTART
```

Ubuntu 24.04 将 `RENDER_USER` 替换为实际拥有图形、音频会话的用户：

```sh
sudo bash stream-kit-preview-98e419f7f85f-ubuntu24.04-amd64-setup.run --user RENDER_USER
```

Windows 安装器创建一个自动启动的 `StreamKitOrchestrator` 系统服务，由该服务统一启动和恢复编码器、网关工作进程。程序运行不需要另装 Node.js/npm，不依赖 VB-CABLE；生产包不包含 Example、测试音源、探针、测试 CA、凭据、模拟器或 SDK。渲染需要登录后的桌面会话；不启用自动登录、不自动重启。Windows UAC 仍适用。

首次在服务器本机打开 `http://127.0.0.1:9000`。静默安装为唯一管理员生成独立密码，凭据保存在受保护的运行配置中，没有共享默认密码。远程设备接入前配置局域网监听、媒体网络与可信 HTTPS，再从应用页复制永久观看链接。首次建立 CA 信任与后续在同一 CA 下更新服务器地址是两个操作。

现有安装目录、运行数据或已注册服务会受到保护，本版不提供安装器原位升级。不要删除数据绕过检查。详见 [Windows 部署说明](https://github.com/bei612/stream-kit/blob/main/deploy/windows/README.md)、[Linux 部署说明](https://github.com/bei612/stream-kit/blob/main/deploy/linux/README.md)和[局域网地址配置](https://github.com/bei612/stream-kit/blob/main/docs/lan-address-configuration.md)。
