# Stream Kit 统一服务端预发布版 2026-11-07.1

待发布草稿：`47c02726` 替代安装包正在构建。必须完成对应 Windows 安装验收并补充结果后才能发布。上一候选 `928c012a` 因安装状态处理缺陷未予发布。

Windows x64 与 Ubuntu 24.04 amd64 候选安装包对应源码 `47c02726c0161ebdec50911422d62845a9b6e59a`。本版修复全新安装首次启动缺少自动配对、原生 HTTPS / HTTP/2 向观看端生成内部 loopback 地址，以及 Windows 静默安装的重启和失败状态处理问题。

## 本版变化

- 全新安装后，打开永久应用链接即可自动注册、配对配置的渲染主机并启动串流。管理端只审批与本次网关客户端证书指纹一致的请求；后续启动复用主机身份，无需手工提交 PIN。
- 启动、会话准入和停止统一匹配配置的渲染端点，避免相同应用编号误命中其他主机。离线、重复端点和身份不一致会明确报错。
- Web 管理页与新版 Android 的首次启动请求允许等待 60 秒，覆盖有时限的自动配对流程；日常控制权心跳时限保持不变。
- 修复 HTTP/2 请求的公开地址生成，可信 HTTPS 观看页使用客户端可达的控制地址。
- Windows 安装器在注册服务前，通过统一原生逻辑准备音频端点。Windows 要求重启时保留自动启动服务并返回 `3010`，不自动重启、不声称服务已就绪；其他安装失败返回非零错误码，避免抑制错误弹窗后错误返回成功。

## 安装与访问

Windows 管理员终端静默安装：

```powershell
.\stream-kit-preview-47c02726c016-windows-amd64-setup.exe /VERYSILENT /SUPPRESSMSGBOXES /SP- /NORESTART
```

Ubuntu 24.04 使用实际运行图形、音频会话的用户名替换 `RENDER_USER`：

```sh
sudo bash stream-kit-preview-47c02726c016-ubuntu24.04-amd64-setup.run --user RENDER_USER
```

安装程序部署 Orchestrator、Sunshine、媒体网关及管理页，并配置启动关系。渲染进程需要已登录的用户图形会话；安装器不启用自动登录、不自动重启。宿主机无需另装 Node.js，不依赖 VB-CABLE。仅支持全新安装，已有程序目录、数据目录或服务会被拒绝；未验证原位升级，不要删除现有数据来绕过检查。

首次在服务器本机打开 `http://127.0.0.1:9000`。静默安装生成唯一管理员密码，安装日志只显示受保护凭据文件的位置；没有共享默认密码。默认监听仅供本机使用。其他电脑、手机接入前，需配置局域网监听、媒体网络及可信 HTTPS，再使用管理页生成的永久观看链接。Android release App 和远程浏览器麦克风要求可信 HTTPS。

无公网域名时，可在支持 mDNS 的同一局域网使用证书覆盖的 `主机名.local`；客户端仍须信任该证书。数字 IP 书签不会随 DHCP 自动改写，跨 VLAN 或禁用组播的网络也不能假定名称发现可用。

详细配置见 [Windows 部署说明](https://github.com/bei612/stream-kit/blob/main/deploy/windows/README.md)和 [Ubuntu 安装说明](https://github.com/bei612/stream-kit/blob/main/deploy/linux/INSTALL.md)。附件包括两端安装包、源码与文件清单、SHA-256 和 SPDX SBOM。生产运行包不含 Example、测试音源、探针、SDK、模拟器、测试 CA 或测试凭据。
