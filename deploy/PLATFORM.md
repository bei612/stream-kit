# Stream-Kit 平台运行文件

本包包含同一源码提交构建的统一管理服务、管理页面、Sunshine 渲染端与 Web/PWA 媒体网关。产品版本、发布通道和完整文件摘要见 `platform-manifest.json`；组件清单保留各自源码版本和许可证。

每个平台使用一个安装包。Windows 可使用 `/VERYSILENT /SUPPRESSMSGBOXES /SP- /NORESTART` 静默安装，系统 UAC 确认仍适用。Ubuntu 24.04 使用 `sudo bash INSTALLER.run --user RENDER_USER`；部署时需有可用的图形与音频会话。运行不需要安装 Node.js/npm、Go、Rust、CMake、UE SDK 或测试工具。

统一安装器初始化外部数据目录、唯一管理员和受管组件。默认管理入口为 `http://127.0.0.1:9000`；自定义端口以安装配置为准。管理员凭据位于数据目录受保护的 `orchestrator.json` 中，不应公开配置文件。不要重复注册独立 Sunshine 服务。

在管理页配置渲染主机，上传应用压缩包或选择本机已有程序，设置程序窗口或桌面采集，再创建观看会话。控制权、观看连接、麦克风目标与音量由同一管理入口调整。通用程序录音需要实际可用的虚拟音频端点对，并在目标程序中选择对应录音设备；驱动是否内置以安装包清单 `audio_driver` 为准。

远程浏览器麦克风需通过可信 HTTPS 访问并由客户端允许录音。网络、证书、端口和音频端点按部署环境配置；重启生效的设置在管理页明确标注。变更前保留外部数据备份，升级时停止活动会话并保留旧版本。安装器不自动重启电脑、不执行数据库降级。

当前 Windows 构建仍存在默认音频选择问题：首次创建虚拟音频设备时，Windows 可能将其选为系统及通信的默认输出，影响依赖默认设备的其他程序。应用内明确选择音频端点不能阻止这一系统行为。此问题尚未修复，当前构建不代表已完成正式生产验收。

Windows 产品构建默认集成开源虚拟音频控制器，采用 Objective Development 公开的 Audio 类共享标识与系统音频类驱动。设备序列号包含发布配置中的邮箱前缀及每次安装生成的随机后缀；这是共享标识，不代表独占 USB 编号或 USB-IF 认证。使用规则见 [共享标识说明](https://github.com/obdev/v-usb/blob/801242072fa035e1839e3571df0d9a18e9cec95c/usbdrv/USB-IDs-for-free.txt)。
