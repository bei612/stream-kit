Source-built unified installer candidates for Windows x64 and Ubuntu 24.04 amd64. The Windows EXE contains the control service, management Web UI, Sunshine, Web/PWA media gateway and audio/video example. The Linux single `.run` contains the three native platform components and Web assets. Node.js/npm and compiler toolchains are build dependencies only; they are not required on deployment hosts.

Run the downloaded setup EXE with `/VERYSILENT /SUPPRESSMSGBOXES /SP- /NORESTART` for silent installation. Windows UAC still applies. See the source archive's `deploy/windows/README.md` for credentials, listener configuration, data retention and deployment boundaries.

On Ubuntu, use `sudo bash INSTALLER.run --user RENDER_USER`; add `--no-start` for installation without a desktop session. Native runtime libraries are resolved through apt. The selected user owns the rendering/audio session and private application data. See `deploy/linux/README.md` for startup and removal.

The workflow builds each platform's components and installer from the same clean source revision, verifies component inventories and publishes SHA-256 plus the source SBOM. Linux additionally extracts the actual package and executes three-component initialization without opening media streams. This proves source construction and package integrity; it does not perform host installation, physical microphone, UE5, native audio-device, GPU or production deployment acceptance. MSYS2 package versions are retained in the build logs; byte-for-byte reproducibility across changing distribution repositories is not claimed.

This is a prerelease. It does not bundle a virtual audio driver or claim professional driver redistribution rights. A compatible endpoint pair must already exist on the server for microphone delivery to a generic recording application. Physical microphone acceptance, authorized bundled-driver installation and remaining release conditions are described in the repository's current delivery records. Publisher signing is excluded from the current delivery scope.
