# 媒体状态协议 v2 与运行观测协议 v1

控制面拥有会话期望状态；网关拥有媒体运行资源。二者通过同一次内部 HTTP 交换收敛，管理页不直接访问设备，也不根据配置推断运行成功。

## 请求与确认

`POST {gateway-prefix}/internal/v2/media-state` 发送 `v2.fixture.json` 所示的完整权威快照。请求头 `X-Stream-State-Signature` 为共享密钥计算的 HMAC-SHA256 十六进制值，签名输入为 UTF-8 `stream-kit/media-state/v2\n` 加原始 JSON 字节。网关验证时间、租约、版本单调性与连接归属后原子替换权威状态。

请求 `schema_version` 必须为 2。每个会话的 `control_epoch` 是数据库持久化的控制权代次，初始为创建版本，控制者变化或会话跨越停止边界时更新为本次提交版本；心跳、音量和正常运行状态更新不改变代次。必须满足 `0 < control_epoch <= revision`，同一会话不能倒退，也不能在代次不变时授予另一个控制者。过期连接从投影移除时允许清空控制者。旧数据库自动增加字段，并一次性以已有会话版本回填。控制面、网关和管理页面需要协调升级；旧请求端点与签名域不兼容，不做降级放行。响应观测格式继续使用 v1。

管理端转移命令同时提交读到的 `expected_controller_connection_id` 与 `expected_control_epoch`；缺字段返回 400，控制权已变化返回 409，避免 A → B → A 后执行过期页面命令。媒体队列在入队和实际交付时都校验授权；每条输入和麦克风命令绑定会话 ID、控制权代次及本次物理连接代次。即使中间状态被合并发布或相同连接 ID 重连，旧命令也不能重新获得权限。麦克风积压超过 60ms 时丢弃，年龄从入队前计算。

键盘快照差分、序号、按键、鼠标按钮、触控、笔及手柄状态由共享会话输入运行时统一持有。控制者变化、断开、租约失效或驱动退出时发送释放/取消/手柄断开；新控制者首个输入前先释放旧输入。空闲时随 20ms 会话时钟检查，调度延迟和传输延迟仍需端到端测量。键盘序号采用 16 位环绕顺序；触点 ID 对应的活动状态总量最多 64 个，超额新触点不转发。浏览器不能借控制通道发送上游生命周期或服务端事件报文。控制通道关闭或共享输入队列溢出时结束该连接，统一释放输入；正常撤权只拒绝控制命令，保留观看。清理成功入队不代表目标操作系统已经执行，断网场景仍需实机验证。

成功返回 HTTP 200、`Cache-Control: no-store` 和 `v1.observation.fixture.json` 所示确认。`X-Stream-Observation-Signature` 使用不同签名域 `stream-kit/media-observation/v1\n` 加响应原始字节。响应 `state_issued_at_ms` 必须对应本次请求，全部 `session_id/revision` 必须与请求精确匹配；不接受跨请求重放、遗漏、重复、额外会话或未经认证的确认。响应上限 1 MiB。控制面仅在完整验证后更新已应用版本与观测。

此确认同时包含“权威状态已接受”和“随后采样的运行资源”，不表示资源已按新策略完成每一帧处理。设备状态不是录音验收。旧版只返回 204 的网关不提供该协议确认，控制面将同步标为失败；发布时必须协调升级控制面与网关，不把旧响应解释为新观测。

## 观测语义

| 字段/状态 | 含义 |
| --- | --- |
| `upstream_active` | 共享上游驱动仍接受命令；不表示客户端 ICE 已连接或画面已显示 |
| `subscribers` | 共享媒体事件订阅数；与控制面已准入连接数分别呈现 |
| `unconfigured` | 没有配置本机目标端点，也没有正在使用的上游麦克风传输能力；观众混音仍可能可用 |
| `idle` | 已配置本机目标端点，但上游尚未运行或已经停止；不证明端点可以打开 |
| `device_open` | 上游运行且本机目标设备未报告致命故障；不证明虚拟端点连通或目标程序选用了该输入 |
| `device_failed` | 本机目标设备报告致命故障；不会回退默认设备 |
| `upstream_transport` | 运行中的上游声明支持麦克风扩展；不证明远端实际录音 |

`device_sample_frames` 包含静音帧，不能当作麦克风音量或成功录音时长。`dropped_frames` 表示提交到设备队列时的拒绝/覆盖，不包含所有输入、网络和设备层丢帧；`xruns` 为设备报告的缓冲异常。设备标识不通过该协议下发给浏览器。

控制面管理接口 `/api/v1/media-control` 保留最后一次验证通过的确认，并单独报告可达性、权威租约、新鲜度和 `observations_expires_at_ms`。观测有效期最多为接收确认后 3 秒，且不超过权威租约；同步失败立即失去当前观测资格。管理页还检查会话版本、截止时间及请求错误，并独立计时过期，即使轮询挂起也不长期显示旧的正常状态。历史确认保留用于诊断，不代表当前状态。

## 资源与验证

共享池索引锁只保护索引；每个 host/app 单独串行建连。设备打开、网络连接不占用全局索引锁，观测和其他应用不会因一个上游启动缓慢而一起阻塞。重连必须等待旧驱动退出；等待被取消不会丢失清理任务。阻塞设备打开持有启动所有权直到资源交付或释放，不能因浏览器取消而重复打开。浏览器只保留只读设备监视对象，设备与传输由驱动独占。正常退出先关闭设备，再驱动控制协议发送断开并等待确认，最长等待 1 秒后释放本地传输；超时不代表远端已确认断开。

运行授权还要求媒体连接已完成注册且未断开。逻辑连接租约尚未过期时，已断开的媒体连接也不能继续发送排队输入或麦克风；同一权限锁和成员锁保护实际交付。最后一个媒体订阅退出后不继续排空旧命令。

Go/Rust 共用请求、响应 fixture 和签名常量测试；Go 覆盖篡改、签名域、请求绑定、版本/会话匹配、过期及状态深拷贝；Rust 覆盖共享上游复用、慢建连隔离、取消恢复和运行观测。`node scripts/smoke-media-contract.cjs PATH_TO_NEW_GATEWAY` 在独立回环监听器验证真实网关 HTTP 协议，结束时停止自己的测试进程。该测试不启动 Sunshine、不打开音频设备、不修改现有服务，不代表实际媒体端到端验收。
