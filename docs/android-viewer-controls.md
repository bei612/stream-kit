# Android 客户端使用

Android 是基于官方 Moonlight Android 源码二开的原生客户端，统一接入平台 WebRTC 和会话权限，不是 WebView 套壳，也不独立直连 Sunshine。当前签名 APK 及验收边界见[发布基线](release-status.md)。

## 安装与导入

下载并安装平台 release APK，升级使用相同项目签名。导入管理员提供的 HTTPS 永久链接 `/watch#key=…`，由 App 完成准入和媒体连接，不填写平台管理员账号。

私有 LAN 使用已有部署 CA，通过 Android 系统正常安装信任；证书必须覆盖服务器地址。不能忽略证书校验。入口提供“修改服务器地址”，更新 HTTPS 地址/端口时保留观看密钥；服务器新地址需先按[网络手册](lan-address-configuration.md)完成身份更新。

## 画面和工具栏

观看使用全部可用区域，不保留常驻顶部标题或大型底部“麦克风/断开”栏。点屏幕边缘“≡”展开工具栏；点遮罩、关闭按钮或返回键收起。隐藏入口按钮后仍可按 Android 返回键展开。

工具栏包含键盘、发送按键、鼠标锁定、全屏、统计、设置、声音、麦克风和退出。画面右上角显示“控制者”或“仅观看”，身份来自服务器连接快照。

Web 和 Android 的核心操作与权限语义一致。两者使用不同原生播放器，浏览器专有的 Canvas/HTMLVideo 与页面风格不作为 Android 设置。

## 权限与麦克风

旁观者的键盘、发送按键、鼠标锁定、操控和麦克风禁用，但可调整本地显示和声音。管理员授予或转移控制权后 UI 同步，获得控制权不会自动录音。

开启麦克风需主动点击及 Android 录音授权。撤权、失联/租约到期、离开前台、音频焦点丢失或停止时清理输入并关闭发送。回前台或重连按当前服务器权限进入，不能自动恢复录音；需要再次主动开启。权限拒绝应显示真实状态，不循环请求或偷偷改系统设置。

只有程序被后台停止、连接明确终止时，结束当前媒体及自动恢复。临时网络故障走同一连接恢复，默认以观众恢复。再次主动打开永久链接可以创建新的准入。

## 设置与生效

| 配置 | 行为 | 生效 |
| --- | --- | --- |
| 鼠标模式 | 相对、跟随、本地光标、点击拖动 | 即时，仍需控制权 |
| 触屏模式 | 原生触摸、相对、本地光标、点击拖动 | 即时，仍需控制权 |
| 光标灵敏度 / 滚轮精度 | 与 Web 对齐配置语义，横向/纵向滚动 | 即时 |
| 工具栏位置及隐藏按钮 | 左/右/上/下，保留返回键入口 | 即时 |
| 本机声音、全屏及统计 | 只作用当前设备 | 即时 |
| 分辨率、帧率、码率、编码及服务器本机声音 | 使用服务默认或当前客户端协商值，受共享上游限制 | 重新连接 |
| 麦克风设备及 AEC/NS/AGC | 原生 WebRTC 音频处理与系统设备 | 重新连接，需重新主动开麦 |

重新连接可能重新分配连接身份，控制权以管理端当前决定为准。设置保存在设备本地，与观看凭据分开。统计仅在用户打开时按需采集，不新增常驻重型监控。

## 设备与验收边界

支持范围受 Android 版本、解码器、输入法、外设及系统权限约束；不是所有手柄、蓝牙耳机和厂商平板都已真机验收。模拟器程序音、麦克风及输入证据不外推物理设备音质，Windows 通过也不覆盖 Linux 模拟器负例。精确版本结果只在[基线](release-status.md)维护。

开发状态机、传输和输入适配见[Android 接入契约](../contracts/android-client.md)。修改 UI 前须同时检查权限、输入释放和前后台行为，不能只隐藏按钮而不停止原生采集。
