# Android 串流操作

观看时画面使用全部可用区域，不保留顶部标题栏或底部麦克风、断开栏。点击屏幕边缘的“≡”展开工具栏；点击遮罩、关闭按钮或返回键收起。隐藏入口按钮后仍可按 Android 返回键展开。

工具栏提供键盘、发送按键、锁定鼠标、全屏、统计信息、设置、声音、麦克风和退出串流。输入与麦克风权限来自同一个服务端连接状态；观看者不能自行取得控制权。麦克风仍需主动点击及 Android 录音授权，修改偏好不会自动开启录音。

画面右上角持续显示“控制者”或“仅观看”。仅观看时，键盘、发送按键、鼠标锁定、操控模式和麦克风入口禁用；用户仍可调整本机播放与界面设置。管理端授予或转移控制权后，身份标识和工具栏同步更新并提示结果；撤权时停止输入和麦克风。获得控制权不会自动开始录音。

连接入口的“修改服务器地址”保留当前应用的观看密钥，只更新 HTTPS 地址及端口。服务器更换 IP 后，应由管理员按[局域网地址配置](lan-address-configuration.md)更新服务身份与公开地址；沿用原 CA 时无需重新安装客户端信任。客户端自身更换 IP 不改变观看密钥，重新连接后仍由管理端决定控制权。

当前公开 APK 为 [`20261109.6`](https://github.com/bei612/stream-kit/releases/tag/v0.1.0-android-preview.20261109.6)（源码 `df7cd87b`、版本码 `1000013`），具体签名与来源见[发布记录](evidence/android-release-20261109-6.json)。本机控制端与网关仍为 `98e419f7`，尚未更新到服务端公开版本 `40146db2`，不能把发布记录当作本机安装完成。

此前 `20261109.2`（源码 `6591f2b9`）的实体平板与模拟器交接记录见[版本证据](evidence/android-exclusive-control-20261109.json)，与 `98e419f7` Linux 运行时的[真实目标输入检查](evidence/android-stream-input-20261109.json)保留其原版本范围。当前 `.6` APK 与 `3d4f248c` 服务端也已完成[六阶段输入与控制交接检查](evidence/android-stream-input-3d4f248c-20261110.json)：一个上游、两个客户端，验证目标实际输入及撤权拒绝，不扩展为本机最新服务端验收。

当前 `.6` APK 在 Windows 官方模拟器完成[程序声音、麦克风到原生录音端点与 Web 观看端及撤权静音检查](evidence/android-release-audio-windows-20261110.json)，以及[权限拒绝、断网恢复、前后台切换检查](evidence/android-release-lifecycle-windows-20261110.json)。这两项使用本机旧版服务环境；模拟器合成声源不代表真机扬声器、耳机或真人语音质量。相同 APK 在 Linux CI 的近静音失败仍保留，原因尚未确定。

同一 APK 的[真实系统瞬时音频焦点检查](evidence/android-release-focus-windows-20261110.json)也已通过：其他前台媒体服务取得临时焦点时，客户端仍在前台并保持控制身份，麦克风转为关闭；焦点归还后不会自动恢复录音，需要再次主动点击。该检查使用独立测试包和系统公开焦点 API，未修改正式客户端，不代表电话来电或全部设备的声音质量已经验收。

| 配置 | 行为 | 生效方式 |
| --- | --- | --- |
| 鼠标模式 | 相对模式、跟随、本地光标、点击并拖动 | 即时 |
| 触屏模式 | 原生触摸、相对模式、本地光标、点击并拖动 | 即时 |
| 本地光标灵敏度、滚轮精度 | 与 Web 使用相同配置键；支持横向和纵向滚动 | 即时 |
| 工具栏位置、隐藏按钮 | 左、右、上、下；返回键保留可达入口 | 即时 |
| 本机声音、全屏、统计信息 | 不改变共享会话及其他客户端 | 即时 |
| 分辨率、帧率、码率、编码、服务器本机声音 | 继承服务器默认值，或为当前客户端指定协商参数；服务器权限限制保留 | 重新连接 |
| 麦克风输入设备、回声消除、噪声抑制、自动增益 | 系统输入设备及原生 WebRTC 音频处理 | 重新连接；需重新主动开启麦克风 |

重新连接可能重新分配连接标识，控制权仍以后台当前分配为准。只修改操控或界面选项不会重新连接。设置保存于设备本地，不与观看链接凭据混存。

Android 使用原生解码及 WebRTC；Web 的 HTMLVideo/Canvas、浏览器兼容性与页面风格选项不作为 Android 渲染设置。本文列出的操作不代表所有外接鼠标、输入法、手柄或编解码硬件均已经真机验收，具体版本证据见 `docs/evidence/`。

实现分为会话状态 `ManagedSession`、界面 `ViewerChrome`、偏好 `ViewerSettings`、输入适配 `ViewerPointer` / `RemoteKeyboard` 与协议 `ManagedInput`。工具栏打开、后台运行、权限撤销时清理输入；旧手势的延迟回调不能向新手势发送按键释放。统计信息仅在用户打开时每秒采集，不新增常驻监控。
