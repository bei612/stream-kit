# Android 串流操作

观看时画面使用全部可用区域，不保留顶部标题栏或底部麦克风、断开栏。点击屏幕边缘的“≡”展开工具栏；点击遮罩、关闭按钮或返回键收起。隐藏入口按钮后仍可按 Android 返回键展开。

工具栏提供键盘、发送按键、锁定鼠标、全屏、统计信息、设置、声音、麦克风和退出串流。输入与麦克风权限来自同一个服务端连接状态；观看者不能自行取得控制权。麦克风仍需主动点击及 Android 录音授权，修改偏好不会自动开启录音。

| 配置 | 行为 | 生效方式 |
| --- | --- | --- |
| 鼠标模式 | 相对模式、跟随、本地光标、点击并拖动 | 即时 |
| 触屏模式 | 原生触摸、相对模式、本地光标、点击并拖动 | 即时 |
| 本地光标灵敏度、滚轮精度 | 与 Web 使用相同配置键；支持横向和纵向滚动 | 即时 |
| 工具栏位置、隐藏按钮 | 左、右、上、下；返回键保留可达入口 | 即时 |
| 本机声音、全屏、统计信息 | 不改变共享会话及其他客户端 | 即时 |
| 分辨率、帧率、码率、编码、服务器本机声音 | 继承服务器默认值，或为当前客户端指定协商参数；服务器权限限制保留 | 重新连接 |
| 麦克风输入设备、回声消除、噪声抑制、自动增益 | 系统输入设备及原生 WebRTC 音频处理 | 重新连接；需重新主动开启麦克风 |

重新连接可能重新分配连接标识，控制权仍以后台当前分配为准。只修改操控或界面选项不会重新连接。设置保存于设备本地，不与观看链接凭据混存。

Android 使用原生解码及 WebRTC；Web 的 HTMLVideo/Canvas、浏览器兼容性与页面风格选项不作为 Android 渲染设置。本文列出的操作不代表所有外接鼠标、输入法、手柄或编解码硬件均已经真机验收，具体版本证据见 `docs/evidence/`。

实现分为会话状态 `ManagedSession`、界面 `ViewerChrome`、偏好 `ViewerSettings`、输入适配 `ViewerPointer` / `RemoteKeyboard` 与协议 `ManagedInput`。工具栏打开、后台运行、权限撤销时清理输入；旧手势的延迟回调不能向新手势发送按键释放。统计信息仅在用户打开时每秒采集，不新增常驻监控。
