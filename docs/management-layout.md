# 管理端布局与响应式维护

管理端所有受保护路由使用同一工作空间容器、页面标题、栅格、面板和状态组件。布局取决于可用内容宽度，不由各页面单独设置 `max-w-*`。登录和公开观看入口属于独立场景，不套用后台导航。

## 组件责任

| 位置 | 责任 |
| --- | --- |
| `components/layout/Layout.tsx` | 主导航、面包屑、实时连接标识、跳转内容及唯一工作空间容器 |
| `components/layout/Page.tsx` | Page 标题/描述/操作区、ContentGrid、Metric、EmptyState |
| `components/ui/card.tsx` | 统一面板、二级标题、内容及内边距 |
| `components/ui/table.tsx` | 可键盘访问的表格局部滚动，避免页面裁切 |
| `components/ui/button.tsx` | Button 与 LinkButton 共用外观；导航不嵌套按钮 |
| `index.css` | 容器宽度、间距、布局断点及媒体/容器查询 |
| `api/query-client.ts`、`hooks/useQuery.ts` | 原生管理接口投影、请求归属、缓存及取消，不承担布局状态 |

Page 始终保留一个主标题，加载/失败仅替换数据区域。子区域使用面板标题，不能因为某页请求慢就让标题、操作和内容边界整体变化。

## 布局规则

- `--workspace-width` 统一限定最大内容宽度，`--workspace-gutter` 控制所有页面及面包屑共同边距。
- ContentGrid 的 cards/metrics/fields 根据自身可用宽度自动排布；不要在页面复制 viewport 断点和列数。
- detail 在内容容器至少 960px 时提供主区/说明区，其余为单列；settings 在同一条件下使用分区导航和编辑区，窄屏导航自动换行。
- 页面宽度 1024px 起显示侧栏，较窄宽度使用可展开导航。选中路由后收起，Esc 收起并恢复菜单按钮焦点；不另建浮层焦点系统。
- 卡片、栅格子项、fieldset 和输入保持可收缩。长路径、错误和 ID 按区域折行；代码与表格局部滚动，不通过隐藏整页 overflow 掩盖错误。
- 原生 details 保留其展开状态；系统设置所有编辑器保持挂载，分区跳转不卸载草稿，不借标签切换丢弃未保存修改。
- 样式变量来自既有共享主题，不增加字体下载、重型动效或新的 UI/状态依赖。

## 前后端与状态边界

应用操作仍由服务器 lifecycle 决定，参数目录仍由服务器返回；响应式变化不能改变启动、停止、权限或配置应用规则。系统设置的脱敏运行配置通过现有查询库读取，支持取消与重新读取，和各编辑器的期望配置分开显示。

控制权、音频草稿、配置 revision 和运行确认继续遵循[状态管理](managed-session-state.md)。容器切列、导航展开和窗口缩放不触发保存、重启、重新准入或权限恢复。

## 修改与检查

新增页面必须复用 Page 和已有栅格/面板，不另建页面宽度与标题体系。新增表单先复用受控输入及服务端字段目录，保留错误、空态、加载和生效方式。

检查类型、lint 和生产构建后，使用 playwright-cli 操作真实后端及实际构建资源，覆盖桌面、平板和手机，核对所有路由的标题左边界、内容宽度、单一主标题、局部滚动和无整页横向溢出。展开实际设置、切换来源/历史、验证导航和草稿保留并目视截图；空媒体环境的真实拒绝须明确记录，不能称为完整串流验收。安装部署状态见[发布基线](release-status.md)。
