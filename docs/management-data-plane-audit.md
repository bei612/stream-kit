# 管理平面与数据平面一体化审计

本文件记录长期有效的架构核查结论。它描述代码和接口的职责边界，不替代某一次部署环境的运行验收。

## 数据契约与状态来源

- 应用、组件、日志、系统配置和音频目录分别由管理 API 返回，前端通过 `api/client.ts` 的统一响应封套解码，所有普通请求保留 AbortSignal 和超时边界。
- 会话页面以 `GET /api/v1/stream-sessions/overview` 为唯一组合快照来源。快照同时包含会话、媒体租约、已确认 revision、观测有效期和服务器采样时间；页面不再把独立轮询结果拼成一个权限结论。
- 前端只在会话身份、配置 revision、媒体 lease 和观测时效全部匹配时显示“已同步”。保存成功、网关确认和设备实际观测是三个独立事实。
- WebSocket 只负责让查询尽快失效；轮询和重新连接补偿负责最终一致性。断线、迟到结果和组件卸载不会把旧结果写回新的查询身份。
- 控制权转移使用 `expected_controller_connection_id` 与 `expected_control_epoch`；音频目标、音频策略和容量使用各自的 expected 配置。冲突由服务端返回 409，前端保留草稿并要求重新载入。
- 观看连接是一次连接记录，不是永久设备身份。短暂断线可在租约内恢复；重新访问永久链接会产生新的连接。停止的会话只读并按服务端历史保留策略清理，不计入在线人数或容量。

## 页面与组件体系

- 受保护管理路由统一使用 `Layout`、`Page`、`ContentGrid`、`Card`、`QueryWrapper`、`StatusBadge` 和受控输入组件。宽度、间距、断点、局部表格滚动和焦点样式集中在 `index.css` 与共享 token。
- 桌面侧栏和窄屏导航是同一套结构；窄屏使用可展开导航，Escape 恢复菜单按钮焦点，页面不再复制各自的 viewport 列数。
- 加载、错误、空态、正在刷新和权限/生效状态均为独立状态。命令操作以服务端最新反馈为准，不用按钮禁用状态伪造成功。
- 配置编辑器使用本地草稿与服务器 revision 分离模型，实时生效和重启生效由对应服务端 apply policy 决定；页面切换不卸载编辑器，避免丢失未保存草稿。

## i18n 与跨端衔接

- 管理端的公共页面文案统一由 `orchestrator/web/src/i18n/locale.ts` 提供，当前覆盖简体中文和英文；语言选择、`lang`、页面标题、ARIA 文案、加载/失败/空态、登录、观看入口、应用、会话、音频和设置公共表述保持同源。
- 管理端切换语言只写入 `stream-kit.locale` 与观看端已有的 `mlSettings.language`，不修改观看端其他设置。观看 Web 端继续使用其 canonical `Translations` 和五语言目录；Android 继续使用原生 `values-*` 资源，不把浏览器存储当作移动端状态来源。
- 配置字段中由服务端 schema 直接提供的专业字段标签仍以项目现行中文术语为 canonical 业务词汇；新增公共交互文案必须接入管理端消息表，不能继续散落在页面中。

## 本轮证据与边界

- 管理端 `npm run build` 和 `npm run lint` 已通过；Playwright CLI 实际检查了中文/英文登录页、语言切换、英文页面标题、窄屏布局、公开观看无效链接提示、错误态以及受保护路由未登录重定向，控制台无 error。
- Web 数据平面本身已有完整 i18n 和媒体/输入生命周期实现；本轮未改动其传输协议或 Android 原生实现，避免在已验收链路上引入不必要的替代实现。
- 当前 Windows 主机未提供可用的标准 Go SDK；仓库内自动下载的 Go toolchain 缺少完整标准库，因此本机 `go test ./...` 无法作为有效证据。该环境问题不改变本轮前端构建结果，也不应被误报为后端测试通过。
- 7×24 长时 OOM、真实物理麦克风和 Android 真机全链路属于部署级验收，需要按发布基线在目标主机执行；本轮不把静态构建或登录页验收冒称为这些运行证据。
