# 管理页会话与媒体状态

## 后续管理端契约与生命周期修复（2026-11-10）

管理 API 按 Go 的应用记录/生命周期视图、组件状态、操作日志和配置投影建立共享 TypeScript 类型；应用命令返回记录，不伪装成包含运行权限的生命周期视图。fetch、登录和上传使用同一个响应外层校验，拒绝畸形状态、错误字段和分页信息，解析失败不包含原始响应。上传遇到 401 与普通请求一致清除过期管理登录状态；本机登记和上传必须取得实际应用 ID 才进入详情页，不再使用固定等待时间或空 ID 跳转。

查询结果与分页元数据按同一请求代次一起保存，日志下一页由服务器总数计算。刷新明确返回是否取得并应用当前响应；命令提交后的刷新未确认时保留未确认状态，不将其视作全部完成。应用编辑使用已有配置草稿机制，候选入口走同一查询生命周期；观看入口的每个链接/重试各自拥有请求与 iframe 生命周期，旧尝试卸载并取消。请求代次递增统一经过各组件自己的生命周期函数，保留原有陈旧结果拒绝条件。

查询结果归属由生产代码 `createRequestScope` 管理：退休后不再启动新查询，晚到的成功和错误均不能写入后续请求或重新激活后的生命周期。原查询单元测试中的手写 React 替身已移除，改为直接验证实际生产归属对象的异步乱序、退休和重新激活；这些单元证据不替代真实浏览器操作。响应边界测试已加入管理前端 CI。

上述变更在源码 `91f87d34` 的全量管理前端 TypeScript、ESLint、生产构建及响应边界测试已通过，跨平台 CI `42795458858` 六项成功，原 API 文件 25 处显式 `any` 和剩余前端 lint 问题已处理。[独立原生 Windows 服务的 playwright-cli 操作与截图](evidence/management-isolated-cli-91f87d34.json)确认真实日志 33 条分为 20/13 条、参数保存重载、上传后按真实 ID 跳转、无效观看入口重试及移动布局。单独的小体积未授权上传取得实际 401、清除登录并回到登录页；最初大体积未授权上传在隔离 HTTP 环境发生连接重置，保留该失败，未将它解释为生产 HTTPS 行为或修改生产协议绕过。当前已发布 `20261110.4` 与已安装 `571295af` 仍保持原始字节；新源码组件包与维护预检已完成，安装等待 Windows UAC，不能将独立运行验收写成现有安装已更新。

## 数据所有权与读取

`session.Manager` 是应用串流代次、连接、控制者和保存配置的唯一来源。心跳更新连接租约，也会增加会话 `revision`；版本号并不只表示管理员修改了配置。`mediacontrol.Publisher` 保存经过签名、请求绑定、会话版本和音频目标代次验证的网关回执。保存成功、网关确认和实际媒体运行是三个不同事实。

管理页通过管理员鉴权的 `GET /api/v1/stream-sessions/overview` 一次读取 `sampled_at_ms`、`sessions` 和 `media`。响应禁止缓存。读取沿用发布器 → 会话管理器的锁顺序，复制返回值；不会触发发布、启动程序、变更授权或覆盖保存状态。未配置网关时仍返回真实会话，媒体状态明确不可用。

页面使用一份查询缓存、同一轮刷新及既有请求代次保护，保留 WebSocket 失效通知和两秒轮询。音频、容量、目标设备等编辑草稿继续使用现有比较更新机制。应用名称查询独立，不参与证明媒体运行。

## 有效性与时钟

媒体观测必须同时满足网关可达、租约有效、观测新鲜且会话标识和版本完全匹配。服务端仍保留原有签名校验、三秒观测期限及控制代次约束；协议和输入/麦克风授权均未放宽。会话在快照读取前已变更但网关尚未确认时，显示等待同步是正确行为。

页面以服务器采样时间为基准，保守计入完整请求耗时，再按客户端墙钟与单调时钟的较大经过时间老化快照。客户端时钟与服务器的固定偏差不影响租约比较；客户端时钟回拨不能延长有效期，前跳会保守失效。定时器只触发重绘，实际计算每次读取当前时钟，避免新回执被上一次重绘时间误判为来自未来。每秒重绘使停止轮询后的观测最迟在下一次重绘时退出有效显示。

`GET /stream-sessions` 和 `GET /media-control` 保留兼容，但管理页不再拼接两份独立缓存。远端音频路由仍按原有精确版本匹配失败关闭；本次没有凭页面问题改变媒体路由或授权语义。

Android `.6` 发布源码 `df7cd87b` 的 `ManagedSession.connectionFailure` 已同时处理 `CONNECTION_LEASE_EXPIRED`、旧版 `CONNECTION_EXPIRED` 与明确的 `CONNECTION_TERMINATED`：可恢复租约尝试恢复同一连接，明确终止结束该连接。已对照发布提交复核，并非只查看当前工作区。服务端从旧 `98e419f7` 到当前版本的状态码区分与该逻辑兼容；这是调用链源码复核，不替代 Android 原有生命周期运行证据，也不是新的 Android 媒体或音频验收。
