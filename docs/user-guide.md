# Stream Kit 使用手册

本文适用于统一管理端、Web/PWA 观看端及 Android 客户端。安装、服务启停见[部署运维](../deploy/README.md)，当前版本和本机地址见[发布与部署基线](release-status.md)。

## 进入管理后台

在服务器本机使用部署实际配置的管理地址。新安装默认为 `http://127.0.0.1:9000`；已启用 TLS 时使用 `https://127.0.0.1:9000/login`，不能继续使用 HTTP。局域网其他设备使用服务器 LAN IP 或可解析主机名，`127.0.0.1` 在每台设备上都指向它自己。

管理员凭据来自首次安装或已保存配置，没有通用默认密码。密码最低要求是 12 个 UTF-8 字节。忘记凭据时由授权管理员在服务器受保护配置中处理，不能把网关内部账号当作后台账号。

控制台打开后检查 Sunshine 与媒体网关的运行状态。管理网页能打开只说明控制服务可达，不说明应用、编码、媒体 UDP 或目标录音均可用。

## 添加应用

### 服务器已有程序

在应用管理选择本机程序入口，填写名称、可执行文件绝对路径、工作目录、启动参数和采集模式。路径是服务器上的路径；不要填写客户端电脑路径。程序需要的文件和运行库仍由它自身提供。

登记不会自动复制整个原程序目录。删除这类应用只移除平台登记及平台所属文件，外部程序保留。

### 上传程序包

上传 ZIP、7z、RAR、TAR 或受支持的压缩 TAR，等待上传、解压、入口检测和登记完成。若有多个可执行入口，在候选中选择实际启动程序。不要上传加密、分卷包或依赖链接结构的归档。

失败时按页面具体错误检查格式、展开大小、条目数量、空间或入口。不能因进度条结束就认为应用已登记成功。

## 启动参数与采集模式

选择桌面或指定程序采集。桌面模式可能包含服务器其他窗口；程序模式只按已确认的目标身份采集，目标失效不会回退桌面。支持能力以当前编码器返回结果为准。

修改参数时：

1. 在后台停止该应用，等待观看会话及原生实例终止。
2. 确认页面不再显示停止中、运行中或待确认。
3. 修改并保存参数；若其他管理操作已修改配置，重新读取后处理冲突。
4. 下次通过启动按钮或固定观看链接进入时采用新参数。

关闭某个观看页面或点击客户端“断开”只离开该连接，不必然停止共享应用，其他人仍可能观看。即使没有观众，也应通过后台停止应用后再改参数。不要直接结束 UE/Example 进程来代替正常管理停止。

URL 不能临时覆盖后台启动参数。编辑配置失败时原值不应被当作新值已生效。

## 获取永久观看链接

在应用详情启用固定观看链接，**无需先启动串流**即可复制。将链接发给有权观看的设备，或在平板保存书签。客户端打开后自动请求准入，按后台参数启动应用；已运行同一应用时加入共享画面。

链接形如 `https://SERVER:9000/watch#key=…`。其中 key 是准入密钥，不要把它写进公开文档、截图、访问统计或 URL 查询参数。

| 操作 | 结果 |
| --- | --- |
| 再次打开固定链接 | 重新准入，永久密钥不因两分钟票据到期而失效 |
| 轮换链接 | 新密钥替换旧密钥，旧链接不能再入场 |
| 禁用链接 / 删除应用 | 阻止新准入 |
| 断开当前观看连接 / 停止应用 | 收回已经建立的观看；仅轮换密钥不会自动踢出现有连接 |

不要把只有 `hostId/appId` 的裸网关 URL 当作固定观看入口，它没有完整准入凭据。临时邀请是内部接入机制，不是管理员应长期交给 iPad 的书签。

## 在线连接及控制权

在观看会话页查看当前活跃会话，展开在线连接。连接类型和身份显示以服务器为准：

- 观众可以观看和调整本机播放/界面选项，不能控制程序或开启有效麦克风发送。
- 管理员授予一个连接控制权，或把控制权从 A 转交给 B。A 的旧权限随即失效。
- 释放控制权后所有观看者保持只读；获得控制权仍需主动开启麦克风。
- 断网或租约到期先禁用权限；恢复同一连接时以观众进入，不能自动恢复旧控制权。
- 停止应用后媒体终止，客户端不应无限重试并自动重新拉起程序。

应用、渲染会话和客户端连接是不同对象。历史会话仅用于诊断；离线连接不是长期登记的用户。一周后 A/B/C 重新访问会产生新的连接记录，不要求继续沿用旧连接。已停止历史不提供配置入口，默认按当前策略清理最多 100 条、7 天。

## 程序声音与麦克风

先检查客户端本机播放是否静音，并按浏览器提示点击启用声音。浏览器自动播放限制与程序是否启动是两个问题。

远端麦克风按以下链路工作：

1. 管理员选择实际目标节点和专用输出/录音端点对，保存并等待确认。
2. 目标应用在自己的录音设置中选择相应虚拟录音端点。
3. 管理员把唯一控制权交给需要讲话的连接。
4. 该客户端主动开启麦克风并允许系统录音权限。
5. 在目标程序检查录音电平，同时在其他观看端检查广播；两路检查不能互相替代。

Windows 集成开源虚拟音频能力，不要求购买或安装 VB-CABLE；现有虚拟显示驱动只解决显示，不解决录音。Linux 使用渲染用户的专用 PulseAudio/PipeWire-Pulse 设备。

管理页可调整程序音、麦克风音、广播及控制者监听。控制者监听可能使发言者听到自己的回送，按现场需要选择。客户端失权、断开、后台或录音权限被拒绝后停止发送，不能自动偷偷恢复采集。

Web 的短时媒体连接修复与租约到期不同：同一会话、连接及控制代次都未变且先前正在录音时，重新确认服务器权限后可恢复原采集意愿；撤权、租约过期或主动关闭会清除该意愿。Android 还遵循原生前后台及音频焦点规则，恢复后需主动开麦。详见[连接生命周期](../contracts/client-connections/README.md)。

## Web 与 Android 操作

Web 与 Android 均提供键盘、鼠标/触屏操控、设置、声音、权限身份和断开入口。Android 不保留常驻大底栏，工具栏展开时操作，收起后保留画面。原生解码配置与浏览器特有的 Canvas/HTMLVideo 选项不同，不要求两端内部技术完全一致。

Android 导入 HTTPS 固定链接；必要时通过系统正常信任部署 CA。修改服务器地址保留观看密钥，仅更换地址与端口。详细工具栏和生命周期见[Android 手册](android-viewer-controls.md)。

## 多应用与地址变化

同一渲染主机只能同时串流一个应用。需要换应用时先停止当前应用，再打开另一个应用的固定链接。不要用三个不同链接测试三套独立应用并行。

服务器更换 IP 后，按[地址配置手册](lan-address-configuration.md)更新 TLS 身份和相关显式地址，再重启服务。保留原 CA 不需要客户端重装证书或重新编译。数字 IP 书签须修改地址部分，密钥保留；使用可解析且证书覆盖的稳定主机名时仍需确认局域网名称解析有效。

## 常见提示

| 提示 / 现象 | 检查 |
| --- | --- |
| 暂时无法进入 / 应用无法启动 | 后台组件、应用错误、当前主机是否被其他应用占用、图形会话及自动配对 |
| 请先停止观看会话再修改参数 | 在后台停止应用并等终态，单独关闭浏览器不等于停止共享串流 |
| 无 Host 或 App ID / 再次要求网关登录 | 是否误用了裸网关地址，应复制应用详情的永久入口 |
| 地址变更后证书不匹配 | 给原 CA 下证书加入新地址并重启；不要忽略证书警告 |
| 后台正常但黑屏或一直连接 | 另查采集、编码、ICE/UDP、防火墙和客户端解码，不能只看 9000 网页 |
| 麦克风按钮禁用 | 当前连接是否控制者、音频策略是否允许、是否处于终态 |
| 开麦但程序录不到 | 目标录音设备、路由、Windows 隐私授权或 Linux 用户音频服务 |
