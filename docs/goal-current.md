# Stream Kit 交付目标与完成条件

本文件维护 Stream Kit 的长期交付范围，不承载逐次执行日志。实际版本和未完成验收集中见[发布与部署基线](release-status.md)。本目标仅适用于 Stream Kit，不恢复其他项目的历史任务；文档中的目标不代表系统 Goal 状态被自动改为 active 或 complete。

## 产品范围

交付一体化云渲染串流平台：原生 Windows/Linux 服务端，跨平台 Web/PWA 与基于官方源码二开的 Android App，共用应用、连接、唯一控制权、媒体授权和音频路由。只保留一个管理员，不增加多用户账户、重型监控或无关装饰功能。iOS 通过浏览器接入，原生 iOS App 不在范围内。

| 核心要求 | 完成条件 |
| --- | --- |
| 统一源码与运行 | Sunshine、Moonlight Web、Android 及必要上游源码直接纳管，不用 submodule；有来源锁定、许可证、二开及产物身份 |
| 程序发布 | 上传常见归档或登记本机程序绝对路径；安全解压；删除本机登记保留外部原程序 |
| 画面与声音 | 桌面/程序模式可配置；程序模式按真实执行身份约束画面、进程音与输入，不回退泄露桌面 |
| 多端共享 | 同一应用共享一个上游；Web 与 Android 统一准入，不能私自直连创建第二条上游 |
| 唯一权限 | 管理端实时授予/转交/撤销；旁观者、旧代次、断线及过期连接不能继续输入或送麦克风 |
| 麦克风与广播 | 当前控制者主动采集；送到指定录音端点/程序，并与程序音混合广播；正确处理撤权、权限拒绝和生命周期 |
| 固定入口 | 应用启动前可复制永久链接，按后台参数唤起应用并串流；可轮换/禁用，与短时票据分层 |
| 网络身份 | 支持只有 LAN IP 的部署；监听、公开地址、信令及 ICE 一致；地址更新保留 CA、私钥与观看密钥，不绕过 TLS |
| 管理配置 | 所有受支持配置进入统一页面；区分期望/运行值和即时/重连/重启生效；异步结果不覆盖新操作 |
| Android | 原生解码/WebRTC、统一观看入口、工具栏与 Web 核心操作对齐；持久 release 签名及可安装 APK |
| 安装与恢复 | Windows/Linux 每个平台一个安装器，静默优先；安装器建立启动与恢复关系，无需手工补启动项或另装 Node.js |
| 开发与生产隔离 | Example 覆盖画面、输入、程序音与录音；Example、测试声源、探针和开发 CA 不进产品 |
| 发布 | 下载可用的安装器/APK、SHA-256、来源清单及许可证；区分仓库、发布与本机组件版本 |

## 验收口径

- 一个渲染主机同时一个应用串流是当前能力边界；不把多应用登记宣传成多应用并行隔离运行。
- Web 操作使用 playwright-cli 对实际部署页面验收并截图；接口替身、候选页面和构建成功不替代实际运行。
- Android 至少覆盖模拟器安装、固定链接、实际媒体、目标输入与控制交接、麦克风、断网及前后台；模拟器结果不代表真机声音质量。
- 20 客户端四小时稳定性与已有真人语音证据已接受，不重复长跑或要求用户讲话。本轮不要求 Linux/手机真机验收。
- 服务 Auto、组件重启、整机重启和地址迁移分别证明；当前地址入口恢复不冒充完整新地址媒体验收。
- 同一份测试结果只证明其源码、产物和环境。保留失败记录，不降低判据，也不以旧版通过宣称新版本重新通过。
- 不依赖 VB-CABLE、不要求商业发行者证书、不为本产品申请独占 USB 标识；必须保留实际分发的依赖许可和驱动签名校验。

## 实施约束

修改前核对完整调用链、数据所有者、全部消费者、影响面、部署版本和回退点。复用已有平台与成熟依赖，不堆绕过、假实现或业务硬编码，不采用 spec 驱动开发。每项修改先 review，再按影响范围检查和更新相应长期文档；已通过且未受影响的长测不重跑。

共享主机使用独立 Example，保护其他代理维护的 UE、ToDesk、运行数据和用户修改。实际网络中断或整机重启遵守既有维护确认边界。发布前冻结来源身份，不能混用不同源码的组件宣称同源完整包；本机维护部署须明确标识。

只有上述代码、产物和范围内必要验收均有对应事实，才能宣布整个目标完成。当前差距以[发布与部署基线](release-status.md#尚未闭合的生产验收)为准。
