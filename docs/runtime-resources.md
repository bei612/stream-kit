# 运行资源与释放边界

本文维护当前受管运行路径的资源所有权与故障处理。容量是防止无限累积的工程边界，不是进程总内存承诺；编码器、分辨率、客户端数量和系统驱动仍影响实际占用。当前安装及验证范围统一见[发布与部署基线](release-status.md)。

## 持续视频与连接

| 资源 | 所有者及上限 | 回收 / 超限行为 |
| --- | --- | --- |
| GameStream 未完成视频帧 | `VideoDepayloader`，最多 64 帧；包大小和 FEC 分片受协议限制 | 新帧超限丢弃最早保留帧；`VideoStream` 清理保留超过 2 秒的孤立帧 |
| 首帧到达时间表 | `VideoStream`，只对应仍被保留的帧 | 帧消费、丢弃或过期时同步删除，不能随累计帧数增长 |
| 每观看端视频发送队列 | `FrameQueue`，3 帧 | 超限后等待新的 IDR，禁止继续发送跨越丢帧的依赖帧 |
| 每观看端音频发送队列 | `AudioChannel`，3 包、最大排队时长 60 ms | 丢弃过期音频，避免把网络阻塞转成长时间音频延迟 |
| WebRTC 驱动及 UDP 端口 | `PeerConnectionImpl` | 显式关闭与最终所有者释放均通知驱动退出；适用于普通 Tokio 与专用 reactor，不依赖握手成功 |
| 控制反馈 | 每连接 128 条应用消息、16 条状态事件；SCTP 每通道发送缓存 64 KiB | 队列满或实际发送超过 2 秒终止该附件，由统一连接清理释放输入，不静默丢失按键释放语义 |
| 远端通道 / 媒体轨道交接 | 每连接最多 7 个远端通道、2 条远端轨道 | 回调非阻塞入队，超限结束附件；仅接受六种协议输入通道且不重复注册，无麦克风接收者时停止轨道 |
| 麦克风任务 | `MicChannel` 唯一活动任务，授权与上游命令队列共用现有边界 | 换轨或释放取消旧任务；弱引用不保活已离开的上游；控制代次在入队和消费时均检查 |

这些限制作用于应用附件和媒体协议，不改变管理员配置的分辨率、码率及准入权限。依赖视频帧被丢弃后使用现有关键帧恢复机制，不回退为全桌面采集。

## 浏览器与 Android

MSE 兼容解码路径最多保留 60 个待追加片段、16 MiB 待追加 backing allocation。检查发生在翻译与复制之前；堵塞超限走统一失败清理，不能继续累积。原生 `SourceBuffer` 按时间删除历史，正常保留约 5–7 秒，仍受浏览器原生配额限制。合法 H.264 关键帧可以先包含 SEI/AUD，再包含 IDR，不能只检查第一个 NAL。

退出必须清空待追加片段、解除 SourceBuffer 与媒体事件、完成尚未结束的 setup 等待、释放 video URL 并暂停/卸载元素。cleanup 幂等，迟到 sourceopen 不重新挂载已释放的播放器。WebCodecs 路径继续使用既有队列与 `VideoFrame.close()` 所有权。

Canvas 的 `MediaStreamTrackProcessor` 路径由当前 reader 持有读取锁，原生缓冲最多一帧。换轨和关闭通过 reader 取消挂起读取，读取任务在 finally 释放锁；迟到帧由旧读取任务关闭，不交给新渲染器。重叠初始化共用一个 Promise，关闭后初始化结果不能重建 reader。轨道属于传输层，渲染器不擅自停止共享源；不使用轮询定时器等待轨道。

Android `ManagedSession` 以主线程操作代次排除迟到结果，心跳单飞，重试只有一个挂起任务；`NativePeer.close()` 释放 DataChannel、PeerConnection、工厂和音频设备，关闭麦克风并移除视频 sink。网络清理排空后关闭 executor。本次源码审查不等于新 APK 真机或设备声学验收。

## 控制面、缓存与持久化

| 资源 | 边界 |
| --- | --- |
| 公开请求限流 | 每个限流器最多 4096 个对端；计数饱和，过期项由请求驱动清理，无永久清理 goroutine。登录以真实远端 IP 为准，不接受客户端伪造转发头；反向代理后共享其对端额度 |
| 登录体 / HTTP 连接 | 登录体 16 KiB；原生 HTTP 读取头部 10 秒、空闲连接 60 秒。上传有自己的大小/提取预算，不用全请求短超时误伤大包 |
| 控制 API 请求体 | API 路由统一最多 1 MiB，具体处理器可进一步收紧；无 Content-Length 的 chunked 请求同样受限。JSON 统一解析单个文档并读到 EOF，保留字段校验；超限统一 HTTP 413 / REQUEST_TOO_LARGE，非法及尾随文档 400，解析完成前不执行业务变更。会话表单解析错误不得退化为部分字段成功。仅归档上传路由使用配置的文件大小加 1 MiB 表单开销，文件本身仍受上传处理器大小限制 |
| 应用操作锁 | 仅保留正在执行的应用 ID；完成时按唯一所有者原子删除。不存在的 ID、已删除应用和历史操作不永久占用锁表；迟到释放不能解除新操作 |
| GameStream HTTP | 完整请求含读取响应的期限为普通 10 秒 / 长请求 90 秒；响应最多 8 MiB，包含 chunked 响应；超限或超时退出调用 |
| 配对身份 | GameStream TLS 必须匹配配对时保存的完整证书；跳过 DNS 名称不代表跳过证书身份。服务端身份更换必须重新配对 |
| 应用封面缓存 | 网关全局 FIFO，256 条且总计 32 MiB；替换、淘汰和删除主机同步调整占用；单次获取仍受 HTTP 响应上限保护 |
| Sunshine 管理响应 | 应用列表 8 MiB，CSRF 16 KiB，错误摘要最多读取 16 KiB；已有其他管理接口继续使用各自响应上限 |
| 管理事件 | Hub 最多 20 客户端、各 64 条消息；慢端断开后重新读取权威快照，不为慢端创建额外发送 goroutine |
| 会话历史 | 已停止历史最多 100 条 / 7 天；恢复凭据与在线连接保持各自已有有效期，不成为永久设备档案 |
| 组件日志 | 单行最多保留 64 KiB，继续排空超长行；内存环形缓冲与文件轮转各有既有配置 |
| 操作日志 | 服务启动及每小时按 `log.operation_log.max_age_days/max_count` 清理；30 秒执行期限；退出取消并等待任务；数据库错误明确记录。两项均不为正时显式关闭清理，配置修改重启生效 |
| SQLite | 单连接；初始化失败关闭连接，PRAGMA 设置失败不假装成功。删除日志释放数据库内可复用页，不承诺立刻缩小文件，不在线强制 VACUUM |

## 审查与验证范围

本轮沿管理 API、会话及授权、共享上游、原生接收与 WebRTC 驱动、浏览器解码、Android 关闭链、数据库/日志、安装托管边界核查。Sunshine 采集/编码队列使用既有有界队列及原生资源所有权；本轮不修改其二进制，也不把源码阅读当作 GPU 驱动长期稳定证明。

受管产品拒绝未纳入租约和控制代次的旧 WebSocket 串流接口；上游独立运行模式的旧实现不在当前生产支持路径，不能通过关闭媒体授权来启用它。后续若正式开放，须先收敛其无界发送队列和独立上游生命周期。

相关回归包括真实 UDP 连接释放、真实 TLS 配对证书正反例与超大 chunked 响应、原生协议连续交付/缺包、实际浏览器 MSE/WebCodecs、真实 SQLite 清理与服务退出。没有用替代接口或测试探针交付产品。具体结果、源码身份和未验收范围见[审查材料](evidence/runtime-resource-review-20261113.json)。不能据此声称所有平台永不 OOM；尤其不能把旧版本四小时结果当作修改后版本的重新长测。

## 7×24 运行口径

长期运行要求同时覆盖服务端原生进程、Web 管理页/观看页和 Android 原生媒体资源。持续媒体与反复连接/断开是不同负载，内存、句柄/文件描述符、线程/任务、连接、音频端点及 GPU 资源均需检查。短时工作集上升不能单独证明泄漏；应核对预热后是否持续增长、相同连接规模下是否收敛、关闭后所有者是否释放。

部署需明确客户端数量、分辨率、码率和日志/磁盘预算；`max_viewers=0` 是管理员显式取消人数限制，不具有容量或 OOM 安全保证。渲染应用自身（例如 UE）、编码驱动和浏览器/Android 系统原生内存不等同网关队列，不能只看 JavaScript 堆或 Go 堆下结论。

已有四小时结果按原版本保留。按当前发布决策，完成修复和候选产物定向验收后可以发布正式版，168 小时持续观察作为后续验证，不阻塞首次正式发布。代码预算与回收回归不能替代七天实际运行证据；当前未完成该项，也不以定时重启、强制 GC 或隐藏采集错误代替生命周期修复。逐项审查及剩余边界见[生产复审](evidence/production-readiness-review-20261114.json)。
