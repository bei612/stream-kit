# 本机运行组件更新与 HTTPS 切换准备

本记录针对现有 Windows 部署。目标运行版本为 `47c02726c0161ebdec50911422d62845a9b6e59a`，安装包已发布为 `v0.1.0-preview.20261107.1`。**尚未执行本机更新或 HTTPS 切换**；这不是已验证的安装器原位升级功能。

## 已确认的边界

- 程序目录：`C:\Program Files\StreamKit`；运行数据目录：`C:\ProgramData\StreamKit`。
- 当前控制端为 `70ea6f70`，媒体组件为 `66249387`；SCM 服务 `StreamKitOrchestrator` 处于 Running / Auto。
- 新版三组件原始产物位于项目 `.local/release-47c02726/platform`。版本、安装验收与公开附件核验见 [统一安装包证据](unified-installers-47c02726.json)。
- 对比当前控制端与新版，`internal/model`、`internal/store`、`internal/config` 无源码差异；网关 `config.rs`、`configuration.rs` 无差异。这不替代实际配置预检。
- 本机 `drivers/usbip` 中的 7 个文件逐个与已发布安装清单的长度、SHA-256 一致。本次不需要更换该驱动包；音频端点仍由产品本身的准备流程管理。
- 本机旧安装器仅用于首次安装，不执行覆盖安装，不删除数据后重装。不得调用历史硬编码版本和网络参数的 `apply-lan-update.cjs` 或 `apply-watch-update.cjs`。

## 更新前必须满足

1. 已提升权限的新版 `check-config --config C:\ProgramData\StreamKit\orchestrator.json` 和网关 `config check` 成功；分别检查当前配置及准备中的 TLS 配置。只读预检脚本为项目 `.local/management/prepare-delivery-47c02726.cjs`，结果写入同目录 `delivery-47c02726-preflight.json`。
2. 重新核对配置和已安装程序的指纹，服务命令行必须精确属于上述程序与数据目录。所有复制、移动目标必须解析为上述指定目录内部的绝对路径，拒绝符号链接或重解析路径。
3. 管理端读取当前应用和会话状态，明确实际连接数。历史会话记录总数不能当作在线人数。管理员凭据、会话票据、永久链接密钥不得写入公开记录。
4. 更新执行前准备具有唯一名称的运行文件备份目录及管理员/SYSTEM 专用数据备份目录，校验可写权限、空间和文件清单。备份未完成不得替换运行组件。

## 运行组件更新事务

1. 使用原控制程序的 `service stop --config` 停止且只停止归属本部署的 SCM 服务；确认其媒体组件已退出。保留 SCM 注册及 Auto 设置。
2. 停止后复制控制数据库及存在的 WAL/SHM 文件、控制配置、网关配置与持久身份、编码器配置与配对身份。核对副本哈希。外部 UE 程序文件不属于更新或删除对象。
3. 在程序目录内部暂存完整新三组件与平台清单，原生 `verify-platform` 校验暂存内容。保留安装时建立的编码器配置目录及其权限；不得覆盖外部运行配置。
4. 将旧三组件完整目录移动到本次备份位置，再将新目录就位。备份和更换根平台清单、README；旧 `control-maintenance.json` 一并保留在备份中，避免用旧的局部更新记录错误描述新三组件版本。逐项记录完成操作，便于中途失败时反向恢复。
5. 新版 `verify-platform`、原生配置检查必须通过。使用原生 `audio-driver prepare --config` 准备端点，不重装已匹配的驱动包、不改变系统默认音频设备。若返回需要重启，保留明确结果，不自动重启，不宣称就绪。
6. 通过新版 `service start --config` 启动并等待产品就绪。核对健康接口源码版本、两个受管组件状态、管理登录及原有应用登记；保留永久链接和全部原配置。此操作本身不切换 HTTP 入口、证书信任或网络。

## 失败恢复

- 新版尚未启动前失败：反向恢复已移动的目录与平台清单，使用原程序启动原服务。
- 新版启动后检查失败：先停止归属本部署的服务，保留失败日志；把新版目录和已变更的状态移入本次失败留存位置，恢复同一时间点的旧程序与停止时的数据副本，再启动原服务。数据库与 WAL/SHM 必须作为同一组处理，不混用两次运行状态。
- 任何恢复步骤失败即停止后续变更并报告具体已完成操作；不清空目录、不重建管理员、不自动重新初始化应用数据。
- 备份保留至更新及访问核对结束，不在同一操作中递归清理历史备份。

## HTTPS 是独立的待确认切换

现有 HTTP 入口和 LAN CA 信任尚未改变。运行版本更新后，须以新的二进制与当前配置指纹重新绑定 TLS 提案，验证证书链、主机名、配置和回滚副本，然后提交具体入口变化供确认。不能直接应用绑定旧二进制的提案。

确认范围包括本机证书信任及管理/观看入口改为 HTTPS；其他观看设备还需信任公开 CA 证书。仅分发公开证书，不分发 CA 私钥。旧数字 IP 书签不会自动改写；稳定发现入口与动态媒体地址仍按实际部署验证。

本机网络中断或 IP 切换另行遵守既有确认边界；不得为了验收改变 ToDesk 设置、进程、隐私保护或远程连接。独立环境已通过的输入、地址恢复证据不能代替本机结果。已接受的语音与四小时稳定性不重跑。
